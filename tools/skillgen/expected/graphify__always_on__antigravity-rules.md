## graphify

This project has a graphify knowledge graph at graphify-out/.

Rules:
- For codebase or architecture questions, when `graphify-out/graph.json` exists: for an exact node name or ID, run `graphify query "<name>"` (CLI) or `query_graph` (MCP) directly; for a natural-language question, load the graphify skill's `references/query.md` first and follow it in order (vocabulary, lessons, query, source check, feedback). The vocabulary, `reflect` and `save-result` steps are CLI-only; the MCP tools do not cover them. Use `graphify path "<A>" "<B>"` / `shortest_path` for relationships and `graphify explain "<concept>"` / `get_node` for focused concepts. These return a scoped subgraph, usually much smaller than `GRAPH_REPORT.md` or raw grep output.
- If graphify-out/wiki/index.md exists, navigate it instead of reading raw files
- Read graphify-out/GRAPH_REPORT.md only for broad architecture review or when query/path/explain do not surface enough context
- After modifying code files in this session, run `graphify update .` to keep the graph current (AST-only, no API cost)
