Ketik `/graphify` di asisten pengkodean AI Anda dan ia akan memetakan seluruh proyek Anda (kode, dokumen, PDF, gambar, video) menjadi sebuah **knowledge graph** yang dapat Anda **query alih-alih grep** melalui berkas.

- **Pemetaan kode gratis, sepenuhnya lokal.** Kode diurai dengan tree-sitter AST: deterministik, tanpa LLM, tidak ada yang keluar dari mesin Anda. (Dokumen, PDF, gambar, dan video menggunakan model asisten Anda, atau API key yang dikonfigurasi, untuk tahap semantik.)
- **Setiap edge dijelaskan.** Setiap koneksi ditandai `EXTRACTED` (eksplisit di sumber) atau `INFERRED` (diselesaikan oleh graphify), sehingga Anda bisa membedakan mana yang dibaca langsung dari mana yang disimpulkan.
- **Bukan vector index.** Tanpa embeddings, tanpa vector store: sebuah graf nyata yang Anda telusuri. Ajukan pertanyaan, telusuri jalur antara dua hal, atau jelaskan satu konsep.

> [!NOTE]
> **Ingin ini selalu aktif?** [Graphify Cloud](https://app.graphify.com/login) menjaga graf tetap hidup di sepanjang SDLC Anda: dukungan monorepo dan cross-repo, verifikasi formal, dan tinjauan kode dengan pandangan menyeluruh atas SDLC Anda, plus konektor untuk Sentry, Jira, dan lainnya sehingga insiden dan tiket berada di graf yang sama dengan kode Anda. **[Mulai uji coba gratis 14 hari di app.graphify.com](https://app.graphify.com/login)**.

**Mulai** (30 detik):

```bash
uv tool install graphifyy      # install the CLI (or: pipx install graphifyy)
graphify install               # register the skill with your AI assistant
```

Kemudian, di asisten AI Anda:

```
/graphify .
```

Begitu saja. Anda mendapatkan **tiga berkas**:

```
graphify-out/
├── graph.html       open in any browser — click nodes, filter, search
├── GRAPH_REPORT.md  the highlights: key concepts, surprising connections, suggested questions
└── graph.json       the full graph — query it anytime without re-reading your files
```

Graf yang disimpan menyertakan `graph.schema_version` sehingga integrasi dapat mendeteksi
perubahan format yang tidak kompatibel, plus `graph.graphify_version` yang mengidentifikasi
rilis Graphify yang menghasilkannya.

**Bekerja di** Claude Code, Cursor, Codex, Gemini CLI, GitHub Copilot, dan 15+ lainnya — [pilih platform Anda](#install).

## Lihat cara kerjanya

<p align="center">
  <img src="https://raw.githubusercontent.com/Graphify-Labs/graphify/v8/docs/demo-path.svg" alt="graphify path query: a terminal asks for the shortest path between FastAPI and ModelField, and the answer lights up hop by hop across the knowledge graph" width="900">
</p>

Setelah graf dibangun, Anda meng-query-nya alih-alih membaca berkas. Output nyata, graphify dijalankan pada codebase FastAPI yang ditampilkan di atas:

```text
$ graphify explain "APIRouter"
Node: APIRouter
  Source:    routing.py L2210
  Community: 2
  Degree:    47

Connections (47):
  --> RequestValidationError [uses] [INFERRED]
  --> Dependant [uses] [INFERRED]
  --> .get() [method] [EXTRACTED]
  <-- __init__.py [imports] [EXTRACTED]
  ...

$ graphify path "FastAPI" "ModelField"
Shortest path (3 hops):
  FastAPI --uses--> DefaultPlaceholder <--references-- get_request_handler() --references--> ModelField
```

Setiap edge membawa **confidence tag** (`EXTRACTED` = eksplisit di sumber, `INFERRED` = diturunkan melalui resolusi), sehingga Anda bisa membedakan mana yang dibaca langsung dari mana yang disimpulkan. `graphify query "<question>"` mengembalikan subgraf yang dibatasi cakupannya untuk pertanyaan bahasa biasa, dan `graphify path A B` menelusuri bagaimana dua hal apa pun terhubung.

## Apa yang dilakukannya

Apa yang Anda dapatkan langsung dari awal:

| Kemampuan | Apa yang Anda dapatkan |
|---|---|
| **God nodes** | Konsep yang paling banyak terhubung, sehingga Anda melihat ke mana semuanya mengalir |
| **Communities** | Graf dibagi menjadi subsistem (Leiden), dengan label tanpa LLM |
| **Cross-file links** | `calls` / `imports` / `inherits` / `mixes_in` diselesaikan lintas berkas di ~40 bahasa melalui tree-sitter AST |
| **Query, path, explain** | Ajukan pertanyaan, telusuri jalur antara dua hal, atau jelaskan satu konsep, semuanya terhadap `graph.json` |
| **Rationale + doc refs** | Komentar `# NOTE:` / `# WHY:` dan kutipan ADR/RFC menjadi node kelas satu yang tertaut ke kode |
| **Beyond code** | Dokumen, PDF, gambar, dan video/audio semuanya dipetakan ke graf yang sama |
| **Local-first** | Kode diurai secara lokal dengan tree-sitter (tanpa LLM, tidak ada yang keluar dari mesin Anda); hanya tahap semantik atas dokumen/media yang memanggil backend, dan hanya jika Anda mengonfigurasi satu |

## Install

> [!IMPORTANT]
> **Paket resmi:** Paket PyPI adalah `graphifyy` (dua-y). Paket `graphify*` lain di PyPI tidak berafiliasi. Perintah CLI tetap `graphify`.

Repositori sumber resmi adalah [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify).

**Langkah 1 — instal paket:**

```bash
# Recommended (isolated env; if 'graphify' isn't found after, run: uv tool update-shell):
uv tool install graphifyy

# Alternatives:
pipx install graphifyy
pip install graphifyy  # may need PATH setup — see note below
```

**Langkah 2 — daftarkan skill dengan asisten AI Anda:**

```bash
graphify install
```

Begitu saja. Buka asisten AI Anda dan ketik `/graphify .`

Untuk menginstal skill asisten ke repositori saat ini alih-alih ke profil pengguna
Anda, tambahkan `--project`:

```bash
graphify install --project
graphify install --project --platform codex
```

Instalasi dengan cakupan proyek menulis di bawah direktori saat ini, misalnya
`.claude/skills/graphify/SKILL.md` atau `.agents/skills/graphify/SKILL.md` (plus sebuah
sidecar `references/` yang dimuat skill sesuai kebutuhan), dan
mencetak petunjuk `git add` untuk berkas yang dapat di-commit.
Perintah per platform yang mendukung instalasi dengan cakupan proyek menerima flag yang sama,
misalnya `graphify claude install --project` atau `graphify codex install --project`.

> [!TIP]
> Mengalami `command not found`, masalah `pip`-di-Mac/Windows, kutipan PowerShell, penggunaan `uvx`, keanehan PATH git-hook, atau strict mode? Lihat **[Installation](https://docs.graphify.com/installation)** dan **[Troubleshooting](https://docs.graphify.com/troubleshooting)**.

## Buat asisten Anda selalu menggunakan graf

Jalankan ini sekali di proyek Anda setelah membangun graf:

Jalankan `graphify <platform> install` sekali di proyek Anda, misalnya `graphify claude install` atau `graphify codex install` (atau `graphify install --platform <name>`).

Ini menulis berkas konfigurasi kecil yang memberi tahu asisten Anda untuk berkonsultasi dengan knowledge graph untuk pertanyaan tentang codebase, lebih memilih query yang dibatasi cakupannya seperti `graphify query "<question>"` daripada membaca seluruh laporan atau grep berkas mentah.

- **Platform Hook** (Claude Code, Gemini CLI): sebuah hook otomatis aktif sebelum pemanggilan tool bergaya pencarian (dan, di Claude Code, sebelum membaca berkas sumber satu per satu melalui tool Read/Glob) dan mengarahkan asisten Anda ke jalur graf.
- **Platform berkas instruksi** (Codex, OpenCode, Cursor, dll.): berkas instruksi persisten (`AGENTS.md`, `.cursor/rules/`, dll.) memberikan panduan query-first yang sama.

`GRAPH_REPORT.md` tetap tersedia untuk tinjauan arsitektur secara luas.

**CodeBuddy** melakukan dua hal yang sama seperti Claude Code: menulis bagian `CODEBUDDY.md` yang menyuruh CodeBuddy membaca `graphify-out/GRAPH_REPORT.md` sebelum menjawab pertanyaan arsitektur, dan memasang `PreToolUse` hooks (`.codebuddy/settings.json`) yang aktif sebelum perintah pencarian Bash dan pembacaan berkas, mengarahkan ke `graphify query` sebagai gantinya.

**Codex** menulis ke `AGENTS.md`, yang sebenarnya membawa panduan graf yang selalu aktif di platform ini. `graphify codex install` juga mendaftarkan sebuah `PreToolUse` hook di `.codex/hooks.json` (`graphify hook-check`), tetapi entri itu sengaja dibuat **no-op**: Codex Desktop menolak `hookSpecificOutput.additionalContext` pada `PreToolUse`, jadi memancarkan dorongan di sana akan merusak pemanggilan tool Bash. Berbeda dengan Claude Code, di mana hook (`graphify hook-guard`) melakukan pendorongan, di Codex hook aktif dan sengaja tidak melakukan apa pun, dan `AGENTS.md` adalah mekanisme yang selalu aktif.

**Kilo Code** memasang skill Graphify ke `~/.config/kilo/skills/graphify/SKILL.md` dan perintah native `/graphify` ke `~/.config/kilo/command/graphify.md`. `graphify kilo install` juga menulis `AGENTS.md` plus plugin native `tool.execute.before` (`.kilo/plugins/graphify.js` + registrasi `.kilo/kilo.json` atau `.kilo/kilo.jsonc`) sehingga Kilo mendapatkan perilaku pengingat graf yang selalu aktif yang sama melalui konfigurasi `.kilo` native.

**Cursor** menulis `.cursor/rules/graphify.mdc` dengan `alwaysApply: true`, sehingga Cursor menyertakannya di setiap percakapan secara otomatis, tanpa perlu hook.

Untuk menghapus graphify dari semua platform sekaligus: `graphify uninstall` (tambahkan `--purge` untuk juga menghapus `graphify-out/`). Atau gunakan perintah per platform (mis. `graphify claude uninstall`).

## Perintah umum

```bash
/graphify .                        # build graph for current folder
/graphify ./docs --update          # re-extract only changed files
/graphify . --cluster-only         # rerun clustering without re-extracting
/graphify . --cluster-only --resolution 1.5      # more granular communities
/graphify . --cluster-only --exclude-hubs 99     # suppress utility super-hubs from god-node rankings
/graphify . --no-viz               # skip the HTML, just the report + JSON
/graphify . --wiki                 # build a markdown wiki from the graph
graphify export callflow-html      # Mermaid architecture/call-flow HTML (auto-regenerates on every git commit if hook is installed)

/graphify query "what connects auth to the database?"
/graphify path "UserService" "DatabasePool"
/graphify explain "RateLimiter"

/graphify add https://arxiv.org/abs/1706.03762   # fetch a paper and add it
/graphify add <youtube-url>                       # transcribe and add a video

graphify hook install              # auto-rebuild on commit + branch checkout (run `graphify update .` after `git pull` — see "Recommended workflow" below)
graphify merge-graphs a.json b.json              # combine two graphs

graphify prs                       # PR dashboard: CI state, review status, worktree mapping
graphify prs 42                    # deep dive on PR #42 with graph impact
graphify prs --triage              # AI ranks your review queue (uses whatever backend is configured)
graphify prs --conflicts           # PRs sharing graph communities — merge-order risk
```

Lihat [referensi perintah lengkap](#full-command-reference) di bawah.

## Privasi

- **Berkas kode** — diproses secara lokal melalui tree-sitter. Tidak ada yang keluar dari mesin Anda. Corpus yang hanya berisi kode tidak memerlukan API key — `graphify extract` berjalan sepenuhnya offline. Pada repo campuran, tambahkan `--code-only` untuk mengindeks hanya kode dan melewati dokumen/PDF/gambar yang jika tidak akan memerlukan LLM.
- **Video / audio** — ditranskripsikan secara lokal dengan faster-whisper. Tidak ada yang keluar dari mesin Anda.
- **Dokumen, PDF, gambar** — dikirim ke asisten AI Anda untuk ekstraksi semantik (melalui skill `/graphify`, menggunakan model apa pun yang dijalankan sesi IDE Anda). `graphify extract` headless memerlukan `GEMINI_API_KEY` / `GOOGLE_API_KEY` (Gemini), `MOONSHOT_API_KEY` (Kimi), `ANTHROPIC_API_KEY` (Claude), `OPENAI_API_KEY` (OpenAI), `DEEPSEEK_API_KEY` (DeepSeek), instance Ollama yang berjalan (`OLLAMA_BASE_URL`), kredensial AWS melalui provider chain standar (Bedrock - tidak perlu API key, menggunakan IAM), atau binary CLI `claude` (Claude Code - tidak perlu API key, menggunakan langganan Claude Anda). Flag `--dedup-llm` menggunakan key yang sama.
- **Data residency** — `graphify extract` otomatis mendeteksi provider mana yang digunakan berdasarkan API key mana yang disetel (prioritas: Gemini → Kimi → Claude → OpenAI → DeepSeek → Azure → Bedrock → Ollama). Untuk kode dengan persyaratan data-residency, gunakan `--backend ollama` (sepenuhnya lokal) atau berikan flag `--backend` eksplisit. Kimi (`MOONSHOT_API_KEY`) merutekan ke server Moonshot AI di Tiongkok.
- **Tanpa telemetri**, tanpa pelacakan penggunaan, tanpa analitik.
- **Pencatatan query** — setiap pemanggilan `graphify query`, `graphify path`, `graphify explain`, dan MCP `query_graph` dicatat ke `~/.cache/graphify-queries.log` dalam format JSON Lines (timestamp, pertanyaan, corpus, node yang dikembalikan, durasi). Respons subgraf lengkap **tidak** disimpan secara default. Setel `GRAPHIFY_QUERY_LOG_DISABLE=1` untuk menonaktifkan, atau `GRAPHIFY_QUERY_LOG=/dev/null` untuk membungkam tanpa menonaktifkan jalur kode.

## Graphify Cloud

[**Graphify Cloud**](https://app.graphify.com/login) adalah lapisan yang selalu aktif yang dibangun di atas graphify. Alih-alih graf yang Anda bangun ulang sesuai permintaan per folder, ia menjaga satu graf hidup di sepanjang seluruh siklus hidup pengembangan perangkat lunak Anda:

- **80% lebih sedikit token** — memori yang selalu aktif berarti agen Anda berhenti membaca ulang dan menjelaskan ulang codebase di setiap sesi.
- **Monorepo dan cross-repo** — satu graf terhubung di seluruh layanan dan repositori, bukan satu graf per folder.
- **Verifikasi formal** — periksa invarian arsitektur dan dependensi terhadap graf yang hidup.
- **Tinjauan kode dengan pandangan menyeluruh atas SDLC Anda** — lihat bagaimana sebuah perubahan beriak ke seluruh sistem sebelum Anda merge.
- **Konektor SDLC** — tarik Sentry, Jira, dan lainnya, sehingga insiden, tiket, dan kode berada dalam satu graf.
- **Selalu aktif** — diperbarui terus-menerus di latar belakang di seluruh kode, dokumen, dan rapat.

**[Mulai uji coba gratis 14 hari di app.graphify.com &rarr;](https://app.graphify.com/login)**
