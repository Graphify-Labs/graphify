הקלידו `/graphify` בעוזר הקידוד מבוסס הבינה המלאכותית שלכם והוא ימפה את כל הפרויקט שלכם (קוד, מסמכים, קובצי PDF, תמונות, סרטונים) ל**גרף ידע** שאפשר **לתשאל במקום לבצע grep** על הקבצים.

- **מיפוי קוד בחינם, מקומי לחלוטין.** הקוד מנותח באמצעות עץ תחביר מופשט (AST) של tree-sitter: דטרמיניסטי, ללא מודל שפה, ושום דבר לא עוזב את המכונה שלכם. (מסמכים, קובצי PDF, תמונות וסרטונים משתמשים במודל של העוזר שלכם, או במפתח API מוגדר, למעבר סמנטי.)
- **כל קשת מוסברת.** כל חיבור מתויג `EXTRACTED` (מפורש במקור) או `INFERRED` (נפתר על ידי graphify), כך שתוכלו להבחין בין מה שנקרא ישירות לבין מה שהוסק.
- **לא אינדקס וקטורי.** ללא הטמעות, ללא מאגר וקטורי: גרף אמיתי שעוברים בו. שאלו שאלה, עקבו אחר הנתיב בין שני דברים, או הסבירו מושג אחד.

> [!NOTE]
> **רוצים שזה יהיה תמידי?** [Graphify Cloud](https://app.graphify.com/login) שומר על הגרף חי לאורך כל מחזור חיי פיתוח התוכנה שלכם: תמיכה במונורפו ובחוצה-מאגרים, אימות פורמלי, וסקירת קוד עם מבט על של מחזור חיי הפיתוח שלכם, בתוספת מחברים ל-Sentry, Jira ועוד, כך שתקריות וכרטיסים יושבים באותו גרף יחד עם הקוד שלכם. **[התחילו תקופת ניסיון חינם של 14 ימים ב-app.graphify.com](https://app.graphify.com/login)**.

## See it in action

<p align="center">
  <img src="https://raw.githubusercontent.com/Graphify-Labs/graphify/v8/docs/demo-path.svg" alt="graphify path query: a terminal asks for the shortest path between FastAPI and ModelField, and the answer lights up hop by hop across the knowledge graph" width="900">
</p>

ברגע שהגרף נבנה אתם מתשאלים אותו במקום לקרוא קבצים. פלט אמיתי, הרצת graphify על בסיס הקוד של FastAPI שמוצג למעלה:

```text
$ graphify explain "APIRouter"
Node: APIRouter
  Source:    routing.py L2210
  Community: 2
  Degree:    47

Connections (47):
  --> RequestValidationError [uses] [INFERRED]
  --> Dependant [uses] [INFERRED]
  --> .get() [method] [EXTRACTED]
  <-- __init__.py [imports] [EXTRACTED]
  ...

$ graphify path "FastAPI" "ModelField"
Shortest path (3 hops):
  FastAPI --uses--> DefaultPlaceholder <--references-- get_request_handler() --references--> ModelField
```

כל קשת נושאת **תג ביטחון** (`EXTRACTED` = מפורש במקור, `INFERRED` = נגזר באמצעות פתירה), כך שתוכלו להבחין בין מה שנקרא ישירות לבין מה שהוסק. `graphify query "<question>"` מחזיר תת-גרף ממוקד לשאלה בשפה פשוטה, ו-`graphify path A B` עוקב אחר האופן שבו שני דברים כלשהם מתחברים.

## What it does

מה שאתם מקבלים כבר מההתחלה:

| Capability | What you get |
|---|---|
| **צמתי על** | המושגים המחוברים ביותר, כך שאתם רואים דרך מה הכול זורם |
| **קהילות** | הגרף מחולק לתת-מערכות (Leiden), עם תוויות ללא מודל שפה |
| **קישורים חוצי-קבצים** | `calls` / `imports` / `inherits` / `mixes_in` נפתרים על פני כ-40 שפות באמצעות AST של tree-sitter |
| **תשאול, נתיב, הסבר** | שאלו שאלה, עקבו אחר הנתיב בין שני דברים, או הסבירו מושג אחד, הכול מול `graph.json` |
| **הנמקה + הפניות למסמכים** | הערות `# NOTE:` / `# WHY:` וציטוטי ADR/RFC הופכים לצמתים מהשורה הראשונה המקושרים לקוד |
| **מעבר לקוד** | מסמכים, קובצי PDF, תמונות וסרטונים/שמע כולם ממופים לאותו גרף |
| **מקומי-תחילה** | הקוד מנותח מקומית עם tree-sitter (ללא מודל שפה, שום דבר לא עוזב את המכונה שלכם); רק המעבר הסמנטי על מסמכים/מדיה קורא ל-backend, ורק אם הגדרתם כזה |

> [!TIP]
> מריצים את זה על מאגרים רבים או על מונורפו? [Graphify Cloud](https://app.graphify.com/login) עושה זאת ברציפות ומצמצם את הוצאות הטוקנים של הסוכנים ב-80%, עם קישורים חוצי-מאגרים, סקירת קוד לרוחב מחזור חיי הפיתוח, אימות פורמלי, ומחברי Sentry/Jira. [התחילו תקופת ניסיון חינם של 14 ימים &rarr;](https://app.graphify.com/login)

## Install

> [!IMPORTANT]
> **החבילה הרשמית:** חבילת PyPI היא `graphifyy` (עם שני y). חבילות `graphify*` אחרות ב-PyPI אינן קשורות אלינו. פקודת ה-CLI עדיין `graphify`.

מאגר המקור הרשמי הוא [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify).

**שלב 1 — התקינו את החבילה:**

```bash
# Recommended (isolated env; if 'graphify' isn't found after, run: uv tool update-shell):
uv tool install graphifyy

# Alternatives:
pipx install graphifyy
pip install graphifyy  # may need PATH setup — see note below
```

**שלב 2 — רשמו את המיומנות אצל עוזר הבינה המלאכותית שלכם:**

```bash
graphify install
```

זהו. פתחו את עוזר הבינה המלאכותית שלכם והקלידו `/graphify .`

כדי להתקין את מיומנות העוזר במאגר הנוכחי במקום בפרופיל
המשתמש שלכם, הוסיפו `--project`:

```bash
graphify install --project
graphify install --project --platform codex
```

התקנות מוגבלות-פרויקט נכתבות תחת הספרייה הנוכחית, לדוגמה
`.claude/skills/graphify/SKILL.md` או `.agents/skills/graphify/SKILL.md` (בתוספת
קובץ `references/` נלווה שהמיומנות טוענת לפי דרישה), ומדפיסות
רמז `git add` לקבצים שניתן לבצע להם commit.
פקודות לכל פלטפורמה התומכות בהתקנות מוגבלות-פרויקט מקבלות את אותו הדגל,
לדוגמה `graphify claude install --project` או `graphify codex install --project`.

> [!TIP]
> נתקלתם ב-`command not found`, בעיית `pip` ב-Mac/Windows, ציטוט ב-PowerShell, שימוש ב-`uvx`, מוזרויות PATH של git-hook, או מצב קפדני? ראו **[Installation](https://docs.graphify.com/installation)** ו-**[Troubleshooting](https://docs.graphify.com/troubleshooting)**.

## Make your assistant always use the graph

הריצו זאת פעם אחת בפרויקט שלכם לאחר בניית גרף:

הריצו `graphify <platform> install` פעם אחת בפרויקט שלכם, לדוגמה `graphify claude install` או `graphify codex install` (או `graphify install --platform <name>`).

פעולה זו כותבת קובץ תצורה קטן שאומר לעוזר שלכם להיוועץ בגרף הידע עבור שאלות על בסיס הקוד, ולהעדיף שאילתות ממוקדות כגון `graphify query "<question>"` על פני קריאת הדוח המלא או ביצוע grep על קבצים גולמיים.

- **פלטפורמות קרס** (Claude Code, Gemini CLI): קרס נורה אוטומטית לפני קריאות כלי מסוג חיפוש (וב-Claude Code, לפני קריאת קובצי מקור אחד-אחד דרך כלי Read/Glob) ודוחף את העוזר שלכם לכיוון נתיב הגרף.
- **פלטפורמות קובצי-הנחיה** (Codex, OpenCode, Cursor ועוד): קובצי הנחיה קבועים (`AGENTS.md`, `.cursor/rules/` וכו') מספקים את אותה הנחיה של תשאול-תחילה.

`GRAPH_REPORT.md` עדיין זמין לסקירת ארכיטקטורה רחבה.

**CodeBuddy** עושה את אותם שני הדברים כמו Claude Code: כותב מקטע `CODEBUDDY.md` שאומר ל-CodeBuddy לקרוא את `graphify-out/GRAPH_REPORT.md` לפני מענה על שאלות ארכיטקטורה, ומתקין קרסי `PreToolUse` (`.codebuddy/settings.json`) שנורים לפני פקודות חיפוש של Bash וקריאות קבצים, ודוחפים לכיוון `graphify query` במקום זאת.

**Codex** כותב אל `AGENTS.md`, שהוא מה שבפועל נושא את ההנחיה התמידית של הגרף בפלטפורמה זו. `graphify codex install` גם רושם קרס `PreToolUse` ב-`.codex/hooks.json` (`graphify hook-check`), אך רשומה זו היא במכוון **ללא פעולה**: Codex Desktop דוחה `hookSpecificOutput.additionalContext` ב-`PreToolUse`, ולכן פליטת דחיפה שם הייתה שוברת קריאות לכלי Bash. בניגוד ל-Claude Code, שבו הקרס (`graphify hook-guard`) מבצע את הדחיפה, ב-Codex הקרס נורה ובמכוון אינו עושה דבר, ו-`AGENTS.md` הוא המנגנון התמידי.

**Kilo Code** מתקין את מיומנות Graphify אל `~/.config/kilo/skills/graphify/SKILL.md` ופקודת `/graphify` מקורית אל `~/.config/kilo/command/graphify.md`. `graphify kilo install` גם כותב `AGENTS.md` בתוספת תוסף `tool.execute.before` מקורי (`.kilo/plugins/graphify.js` + רישום `.kilo/kilo.json` או `.kilo/kilo.jsonc`) כך ש-Kilo מקבל את אותה התנהגות תזכורת תמידית של הגרף דרך תצורת `.kilo` מקורית.

**Cursor** כותב `.cursor/rules/graphify.mdc` עם `alwaysApply: true`, כך ש-Cursor כולל אותו בכל שיחה אוטומטית, ללא צורך בקרס.

כדי להסיר את graphify מכל הפלטפורמות בבת אחת: `graphify uninstall` (הוסיפו `--purge` כדי למחוק גם את `graphify-out/`). או השתמשו בפקודה לכל פלטפורמה (למשל `graphify claude uninstall`).

## Common commands

```bash
/graphify .                        # build graph for current folder
/graphify ./docs --update          # re-extract only changed files
/graphify . --cluster-only         # rerun clustering without re-extracting
/graphify . --cluster-only --resolution 1.5      # more granular communities
/graphify . --cluster-only --exclude-hubs 99     # suppress utility super-hubs from god-node rankings
/graphify . --no-viz               # skip the HTML, just the report + JSON
/graphify . --wiki                 # build a markdown wiki from the graph
graphify export callflow-html      # Mermaid architecture/call-flow HTML (auto-regenerates on every git commit if hook is installed)

/graphify query "what connects auth to the database?"
/graphify path "UserService" "DatabasePool"
/graphify explain "RateLimiter"

/graphify add https://arxiv.org/abs/1706.03762   # fetch a paper and add it
/graphify add <youtube-url>                       # transcribe and add a video

graphify hook install              # auto-rebuild on commit + branch checkout (run `graphify update .` after `git pull` — see "Recommended workflow" below)
graphify merge-graphs a.json b.json              # combine two graphs

graphify prs                       # PR dashboard: CI state, review status, worktree mapping
graphify prs 42                    # deep dive on PR #42 with graph impact
graphify prs --triage              # AI ranks your review queue (uses whatever backend is configured)
graphify prs --conflicts           # PRs sharing graph communities — merge-order risk
```

ראו את [מסמך העיון המלא של הפקודות](#full-command-reference) למטה.

## Privacy

- **קובצי קוד** — מעובדים מקומית דרך tree-sitter. שום דבר לא עוזב את המכונה שלכם. אוסף קוד בלבד אינו דורש מפתח API — `graphify extract` רץ לגמרי במצב לא מקוון. במאגר מעורב, הוסיפו `--code-only` כדי לאנדקס רק את הקוד ולדלג על המסמכים/קובצי PDF/תמונות שאחרת היו דורשים מודל שפה.
- **וידאו / שמע** — מתומלל מקומית עם faster-whisper. שום דבר לא עוזב את המכונה שלכם.
- **מסמכים, קובצי PDF, תמונות** — נשלחים לעוזר הבינה המלאכותית שלכם לחילוץ סמנטי (דרך מיומנות `/graphify`, בעזרת כל מודל שמריצה סשן ה-IDE שלכם). `graphify extract` ללא ממשק דורש `GEMINI_API_KEY` / `GOOGLE_API_KEY` (Gemini), `MOONSHOT_API_KEY` (Kimi), `ANTHROPIC_API_KEY` (Claude), `OPENAI_API_KEY` (OpenAI), `DEEPSEEK_API_KEY` (DeepSeek), מופע Ollama פעיל (`OLLAMA_BASE_URL`), אישורי AWS דרך שרשרת הספק הסטנדרטית (Bedrock - לא נדרש מפתח API, משתמש ב-IAM), או את קובץ ההרצה `claude` CLI (Claude Code - לא נדרש מפתח API, משתמש במנוי Claude שלכם). הדגל `--dedup-llm` משתמש באותו מפתח.
- **מקום אחסון הנתונים** — `graphify extract` מזהה אוטומטית באיזה ספק להשתמש על סמך מפתח ה-API שהוגדר (עדיפות: Gemini → Kimi → Claude → OpenAI → DeepSeek → Azure → Bedrock → Ollama). עבור קוד עם דרישות מקום אחסון נתונים, השתמשו ב-`--backend ollama` (מקומי לחלוטין) או העבירו דגל `--backend` מפורש. Kimi (`MOONSHOT_API_KEY`) מנתב לשרתי Moonshot AI בסין.
- **ללא טלמטריה**, ללא מעקב שימוש, ללא אנליטיקה.
- **רישום שאילתות** — כל קריאת `graphify query`, `graphify path`, `graphify explain` ו-MCP `query_graph` נרשמת אל `~/.cache/graphify-queries.log` בפורמט JSON Lines (חותמת זמן, שאלה, אוסף, צמתים שהוחזרו, משך). תגובות תת-גרף מלאות **אינן** נשמרות כברירת מחדל. הגדירו `GRAPHIFY_QUERY_LOG_DISABLE=1` כדי לוותר, או `GRAPHIFY_QUERY_LOG=/dev/null` כדי להשתיק בלי להשבית את נתיב הקוד.

## Graphify Cloud

[**Graphify Cloud**](https://app.graphify.com/login) היא השכבה התמידית הבנויה מעל graphify. במקום גרף שאתם בונים מחדש לפי דרישה לכל תיקייה, היא שומרת על גרף חי יחיד לאורך כל מחזור חיי פיתוח התוכנה שלכם:

- **80% פחות טוקנים** — זיכרון תמידי אומר שהסוכנים שלכם מפסיקים לקרוא ולהסביר מחדש את בסיס הקוד בכל סשן.
- **מונורפו וחוצה-מאגרים** — גרף מחובר אחד על פני כל שירות ומאגר, ולא גרף לכל תיקייה.
- **אימות פורמלי** — בדקו משתמרים (invariants) של ארכיטקטורה ותלויות מול הגרף החי.
- **סקירת קוד עם מבט על של מחזור חיי הפיתוח שלכם** — ראו כיצד שינוי מתפשט על פני כל המערכת לפני שאתם ממזגים.
- **מחברי SDLC** — משכו פנימה את Sentry, Jira ועוד, כך שתקריות, כרטיסים וקוד חיים בגרף אחד.
- **תמידי** — מתעדכן ברציפות ברקע על פני קוד, מסמכים ופגישות.
