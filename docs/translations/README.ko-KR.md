AI 코딩 어시스턴트에서 `/graphify`를 입력하면, 프로젝트 전체(코드, 문서, PDF, 이미지, 동영상)를 **지식 그래프**로 매핑하여 **파일을 grep 하는 대신 쿼리**할 수 있습니다.

- **코드 매핑은 무료, 완전히 로컬.** 코드는 tree-sitter AST로 파싱됩니다. 결정론적이고, LLM이 필요 없으며, 그 무엇도 사용자의 기기를 떠나지 않습니다. (문서, PDF, 이미지, 동영상은 어시스턴트의 모델이나 설정된 API 키를 사용해 시맨틱 처리를 거칩니다.)
- **모든 엣지에 설명이 붙습니다.** 각 연결은 `EXTRACTED`(소스에 명시됨) 또는 `INFERRED`(graphify가 해석함)로 태그가 지정되어, 직접 읽은 것과 추론된 것을 구분할 수 있습니다.
- **벡터 인덱스가 아닙니다.** 임베딩도, 벡터 저장소도 없습니다. 직접 순회하는 진짜 그래프입니다. 질문을 하거나, 두 대상 사이의 경로를 추적하거나, 하나의 개념을 설명할 수 있습니다.

> [!NOTE]
> **이것을 상시 가동으로 두고 싶나요?** [Graphify Cloud](https://app.graphify.com/login)는 SDLC 전반에 걸쳐 그래프를 실시간으로 유지합니다. 모노레포 및 리포지토리 간 지원, 형식 검증, SDLC를 한눈에 내려다보는 코드 리뷰, 그리고 Sentry, Jira 등의 커넥터로 인시던트와 티켓이 코드와 같은 그래프 위에 놓입니다. **[app.graphify.com에서 14일 무료 체험 시작하기](https://app.graphify.com/login)**.


```
graphify-out/
├── graph.html       open in any browser — click nodes, filter, search
├── GRAPH_REPORT.md  the highlights: key concepts, surprising connections, suggested questions
└── graph.json       the full graph — query it anytime without re-reading your files
```

영속화된 그래프에는 통합 측이 호환되지 않는 포맷 변경을 감지할 수 있도록
`graph.schema_version`이 포함되며, 그것을 생성한 Graphify 릴리스를 식별하는
`graph.graphify_version`도 함께 포함됩니다.

## 실제 동작 예시

<p align="center">
  <img src="https://raw.githubusercontent.com/Graphify-Labs/graphify/v8/docs/demo-path.svg" alt="graphify path query: a terminal asks for the shortest path between FastAPI and ModelField, and the answer lights up hop by hop across the knowledge graph" width="900">
</p>

그래프가 구축되면 파일을 읽는 대신 그래프를 쿼리합니다. 위에 표시된 FastAPI 코드베이스에서 graphify를 실행한 실제 출력입니다:

```text
$ graphify explain "APIRouter"
Node: APIRouter
  Source:    routing.py L2210
  Community: 2
  Degree:    47

Connections (47):
  --> RequestValidationError [uses] [INFERRED]
  --> Dependant [uses] [INFERRED]
  --> .get() [method] [EXTRACTED]
  <-- __init__.py [imports] [EXTRACTED]
  ...

$ graphify path "FastAPI" "ModelField"
Shortest path (3 hops):
  FastAPI --uses--> DefaultPlaceholder <--references-- get_request_handler() --references--> ModelField
```

모든 엣지에는 **신뢰도 태그**(`EXTRACTED` = 소스에 명시됨, `INFERRED` = 해석으로 도출됨)가 붙어 있어, 직접 읽은 것과 추론된 것을 구분할 수 있습니다. `graphify query "<question>"`는 평이한 언어의 질문에 대해 범위가 좁혀진 서브그래프를 반환하고, `graphify path A B`는 임의의 두 대상이 어떻게 연결되는지를 추적합니다.

## 무엇을 하는가

기본 제공으로 얻는 것:

| 기능 | 얻는 것 |
|---|---|
| **갓 노드(God nodes)** | 가장 많이 연결된 개념으로, 모든 것이 무엇을 거쳐 흐르는지 보입니다 |
| **커뮤니티(Communities)** | 그래프를 서브시스템으로 분할(Leiden), LLM 없는 라벨 포함 |
| **파일 간 링크** | tree-sitter AST를 통해 약 40개 언어에 걸쳐 `calls` / `imports` / `inherits` / `mixes_in` 해석 |
| **쿼리, 경로, 설명** | 질문하기, 두 대상 사이의 경로 추적, 또는 하나의 개념 설명 —— 모두 `graph.json`을 대상으로 |
| **근거 + 문서 참조** | `# NOTE:` / `# WHY:` 주석과 ADR/RFC 인용이 코드에 연결된 일급 노드가 됩니다 |
| **코드를 넘어서** | 문서, PDF, 이미지, 동영상/오디오가 모두 같은 그래프로 매핑됩니다 |
| **로컬 우선** | 코드는 tree-sitter로 로컬에서 파싱됩니다(LLM 없음, 그 무엇도 기기를 떠나지 않음). 문서/미디어에 대한 시맨틱 처리만 백엔드를 호출하며, 그것도 설정한 경우에만 호출합니다 |

> [!TIP]
> 여러 리포지토리나 모노레포에 걸쳐 실행하나요? [Graphify Cloud](https://app.graphify.com/login)는 이를 지속적으로 수행하고 에이전트 토큰 지출을 80% 절감합니다. 리포지토리 간 링크, SDLC 전반의 코드 리뷰, 형식 검증, Sentry/Jira 커넥터 포함. [14일 무료 체험 시작하기 &rarr;](https://app.graphify.com/login)

## Install

> [!IMPORTANT]
> **공식 패키지:** PyPI 패키지는 `graphifyy`(y가 두 개)입니다. PyPI의 다른 `graphify*` 패키지는 본 프로젝트와 무관합니다. CLI 명령은 여전히 `graphify`입니다.

공식 소스 리포지토리는 [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) 입니다.

**1단계 —— 패키지 설치:**

```bash
# Recommended (isolated env; if 'graphify' isn't found after, run: uv tool update-shell):
uv tool install graphifyy

# Alternatives:
pipx install graphifyy
pip install graphifyy  # may need PATH setup — see note below
```

**2단계 —— AI 어시스턴트에 스킬 등록:**

```bash
graphify install
```

이게 전부입니다. AI 어시스턴트를 열고 `/graphify .`를 입력하세요.

사용자 프로필 대신 현재 리포지토리에 어시스턴트 스킬을
설치하려면 `--project`를 추가하세요:

```bash
graphify install --project
graphify install --project --platform codex
```

프로젝트 범위 설치는 현재 디렉터리 아래에 기록됩니다. 예를 들어
`.claude/skills/graphify/SKILL.md` 또는 `.agents/skills/graphify/SKILL.md`(그리고 스킬이
필요할 때 로드하는 `references/` 사이드카)가 생성되며,
커밋할 수 있는 파일에 대해서는 `git add` 힌트를 출력합니다.
프로젝트 범위 설치를 지원하는 플랫폼별 명령도 동일한 플래그를 받습니다.
예를 들어 `graphify claude install --project` 또는 `graphify codex install --project` 입니다.

> [!TIP]
> `command not found`, Mac/Windows에서의 `pip` 문제, PowerShell 따옴표 문제, `uvx` 사용법, git 훅의 PATH 관련 특이 사항, 또는 strict 모드 문제를 겪고 있나요? **[Installation](https://docs.graphify.com/installation)** 과 **[Troubleshooting](https://docs.graphify.com/troubleshooting)** 을 참조하세요.

`--platform agents`(별칭 `--platform skills`)는 범용 크로스프레임워크 [Agent-Skills](https://github.com/anthropics/skills) 위치를 대상으로 합니다. 전역 설치에는 사양에 정의된 사용자 전역 경로 `~/.agents/skills/`(`npx skills`와 사양을 준수하는 프레임워크가 읽음)를, 프로젝트(`--project`) 설치에는 `./.agents/skills/`를 사용합니다. 기본 `graphify install`은 설계상 단일 플랫폼(Claude Code)으로 유지됩니다 —— `.agents/skills`를 읽는 모든 프레임워크가 스킬을 발견할 수 있도록 하려면 이름이 지정된 `agents` 플랫폼을 사용하세요.

> Codex는 `/graphify` 대신 `$graphify`를 사용합니다.

## 어시스턴트가 항상 그래프를 사용하게 만들기

그래프를 구축한 후, 프로젝트에서 한 번 실행하세요:

프로젝트에서 `graphify <platform> install`을 한 번 실행하세요. 예를 들어 `graphify claude install` 또는 `graphify codex install`(또는 `graphify install --platform <name>`)입니다.

이것은 작은 설정 파일을 기록하여, 코드베이스 관련 질문에는 지식 그래프를 참조하고, 전체 리포트를 읽거나 원본 파일을 grep 하는 대신 `graphify query "<question>"`과 같이 범위가 좁혀진 쿼리를 우선하도록 어시스턴트에 지시합니다.

- **훅 플랫폼**(Claude Code, Gemini CLI): 검색 유형의 도구 호출 전에(그리고 Claude Code에서는 Read/Glob 도구로 소스 파일을 하나씩 읽기 전에) 훅이 자동으로 발동하여 어시스턴트를 그래프 경로로 유도합니다.
- **지시 파일 플랫폼**(Codex, OpenCode, Cursor 등): 영속적인 지시 파일(`AGENTS.md`, `.cursor/rules/` 등)이 동일한 "쿼리 우선" 안내를 제공합니다.

`GRAPH_REPORT.md`는 폭넓은 아키텍처 리뷰에 여전히 사용할 수 있습니다.

**CodeBuddy**는 Claude Code와 동일한 두 가지를 수행합니다. 아키텍처 질문에 답하기 전에 `graphify-out/GRAPH_REPORT.md`를 읽도록 CodeBuddy에 지시하는 `CODEBUDDY.md` 섹션을 기록하고, Bash 검색 명령과 파일 읽기 전에 발동하여 `graphify query` 사용을 유도하는 `PreToolUse` 훅(`.codebuddy/settings.json`)을 설치합니다.

**Codex**는 `AGENTS.md`에 기록하며, 이것이 이 플랫폼에서 실제로 상시 가동 그래프 안내를 담당하는 것입니다. `graphify codex install`은 `.codex/hooks.json`에 `PreToolUse` 훅(`graphify hook-check`)도 등록하지만, 그 항목은 의도적으로 **아무 동작도 하지 않습니다(no-op)**. Codex Desktop은 `PreToolUse`의 `hookSpecificOutput.additionalContext`를 거부하므로, 거기서 넛지를 내보내면 Bash 도구 호출이 깨지기 때문입니다. 훅(`graphify hook-guard`)이 넛지를 수행하는 Claude Code와 달리, Codex에서는 훅이 발동해도 의도적으로 아무것도 하지 않으며, `AGENTS.md`가 상시 가동 메커니즘이 됩니다.

**Kilo Code**는 Graphify 스킬을 `~/.config/kilo/skills/graphify/SKILL.md`에, 네이티브 `/graphify` 명령을 `~/.config/kilo/command/graphify.md`에 설치합니다. `graphify kilo install`은 `AGENTS.md`와 더불어 네이티브 `tool.execute.before` 플러그인(`.kilo/plugins/graphify.js` + `.kilo/kilo.json` 또는 `.kilo/kilo.jsonc` 등록)도 기록하므로, Kilo는 네이티브 `.kilo` 설정을 통해 동일한 상시 가동 그래프 리마인더 동작을 얻습니다.

**Cursor**는 `alwaysApply: true`가 설정된 `.cursor/rules/graphify.mdc`를 기록하므로, Cursor는 훅 없이 모든 대화에 자동으로 그것을 포함합니다.

모든 플랫폼에서 graphify를 한 번에 제거하려면: `graphify uninstall`(`--purge`를 추가하면 `graphify-out/`도 삭제). 또는 플랫폼별 명령(예: `graphify claude uninstall`)을 사용하세요.

## 처리하는 파일

graphify는 약 40개의 프로그래밍 언어를 tree-sitter AST로 로컬에서 파싱하고, 선택적 시맨틱 처리를 통해 문서, PDF, 이미지, 오디오/동영상을 매핑합니다. 전체 목록은 **[Supported inputs](https://docs.graphify.com/concepts/supported-inputs)** 에 있습니다.

---

## 자주 쓰는 명령

```bash
/graphify .                        # build graph for current folder
/graphify ./docs --update          # re-extract only changed files
/graphify . --cluster-only         # rerun clustering without re-extracting
/graphify . --cluster-only --resolution 1.5      # more granular communities
/graphify . --cluster-only --exclude-hubs 99     # suppress utility super-hubs from god-node rankings
/graphify . --no-viz               # skip the HTML, just the report + JSON
/graphify . --wiki                 # build a markdown wiki from the graph
graphify export callflow-html      # Mermaid architecture/call-flow HTML (auto-regenerates on every git commit if hook is installed)

/graphify query "what connects auth to the database?"
/graphify path "UserService" "DatabasePool"
/graphify explain "RateLimiter"

/graphify add https://arxiv.org/abs/1706.03762   # fetch a paper and add it
/graphify add <youtube-url>                       # transcribe and add a video

graphify hook install              # auto-rebuild on commit + branch checkout (run `graphify update .` after `git pull` — see "Recommended workflow" below)
graphify merge-graphs a.json b.json              # combine two graphs

graphify prs                       # PR dashboard: CI state, review status, worktree mapping
graphify prs 42                    # deep dive on PR #42 with graph impact
graphify prs --triage              # AI ranks your review queue (uses whatever backend is configured)
graphify prs --conflicts           # PRs sharing graph communities — merge-order risk
```

아래의 [전체 명령 레퍼런스](#full-command-reference)를 참조하세요.

## 개인정보 보호

- **코드 파일** —— tree-sitter를 통해 로컬에서 처리됩니다. 그 무엇도 기기를 떠나지 않습니다. 코드 전용 코퍼스는 API 키가 필요 없으며, `graphify extract`는 완전히 오프라인으로 실행됩니다. 혼합 리포지토리에서는 `--code-only`를 추가하면 코드만 인덱싱하고, 원래 LLM이 필요한 문서/PDF/이미지를 건너뜁니다.
- **동영상 / 오디오** —— faster-whisper로 로컬에서 전사됩니다. 그 무엇도 기기를 떠나지 않습니다.
- **문서, PDF, 이미지** —— 시맨틱 추출을 위해 AI 어시스턴트로 전송됩니다(`/graphify` 스킬을 통해, IDE 세션이 실행하는 모델을 사용). 헤드리스 `graphify extract`에는 `GEMINI_API_KEY` / `GOOGLE_API_KEY`(Gemini), `MOONSHOT_API_KEY`(Kimi), `ANTHROPIC_API_KEY`(Claude), `OPENAI_API_KEY`(OpenAI), `DEEPSEEK_API_KEY`(DeepSeek), 실행 중인 Ollama 인스턴스(`OLLAMA_BASE_URL`), 표준 공급자 체인을 통한 AWS 자격 증명(Bedrock —— API 키 불필요, IAM 사용), 또는 `claude` CLI 바이너리(Claude Code —— API 키 불필요, Claude 구독 사용) 중 하나가 필요합니다. `--dedup-llm` 플래그는 동일한 키를 사용합니다.
- **데이터 레지던시** —— `graphify extract`는 설정된 API 키를 기준으로 어떤 공급자를 사용할지 자동 감지합니다(우선순위: Gemini → Kimi → Claude → OpenAI → DeepSeek → Azure → Bedrock → Ollama). 데이터 레지던시 요구 사항이 있는 코드에는 `--backend ollama`(완전 로컬)를 사용하거나 명시적인 `--backend` 플래그를 전달하세요. Kimi(`MOONSHOT_API_KEY`)는 중국에 있는 Moonshot AI 서버로 라우팅됩니다.
- **텔레메트리 없음**, 사용량 추적 없음, 분석 없음.
- **쿼리 로깅** —— 모든 `graphify query`, `graphify path`, `graphify explain`, 그리고 MCP `query_graph` 호출은 JSON Lines 형식으로 `~/.cache/graphify-queries.log`에 기록됩니다(타임스탬프, 질문, 코퍼스, 반환된 노드 수, 소요 시간). 전체 서브그래프 응답은 기본적으로 저장되지 **않습니다**. 옵트아웃하려면 `GRAPHIFY_QUERY_LOG_DISABLE=1`을 설정하거나, 코드 경로를 비활성화하지 않고 조용히 하려면 `GRAPHIFY_QUERY_LOG=/dev/null`을 설정하세요.

## Graphify Cloud

[**Graphify Cloud**](https://app.graphify.com/login)는 graphify 위에 구축된 상시 가동 계층입니다. 폴더별로 필요할 때마다 다시 구축하는 그래프 대신, 소프트웨어 개발 수명 주기 전반에 걸쳐 하나의 실시간 그래프를 유지합니다:

- **토큰 80% 절감** —— 상시 가동 메모리 덕분에 에이전트가 매 세션마다 코드베이스를 다시 읽고 다시 설명하지 않아도 됩니다.
- **모노레포와 리포지토리 간** —— 폴더별 그래프가 아니라, 모든 서비스와 리포지토리를 아우르는 하나의 연결된 그래프.
- **형식 검증** —— 아키텍처와 의존성 불변 조건을 실시간 그래프에 비추어 검사합니다.
- **SDLC를 한눈에 내려다보는 코드 리뷰** —— 병합하기 전에 변경이 시스템 전체로 어떻게 파급되는지 확인합니다.
- **SDLC 커넥터** —— Sentry, Jira 등을 끌어와, 인시던트, 티켓, 코드가 하나의 그래프 안에 자리합니다.
- **상시 가동** —— 코드, 문서, 미팅에 걸쳐 백그라운드에서 지속적으로 업데이트합니다.

**[app.graphify.com에서 14일 무료 체험 시작하기 &rarr;](https://app.graphify.com/login)**

## graphify 위에 구축하기

graphify 생태계에서 무언가를 만들고 있나요? 그것은 권장됩니다. 프로젝트 이름에 "graphify"를 사용한다면(예: `graphify-dashboard` 또는 `graphify-action`), 그것이 커뮤니티가 만든 것이며 Graphify Labs와 제휴하거나 그로부터 보증받지 않았음을 명확히 하는 짧은 안내를 README에 추가하세요. "graphify"와 graphify 로고는 Graphify Labs의 상표입니다. 공식적인 지위를 암시하는 방식으로 사용하지 마세요.
