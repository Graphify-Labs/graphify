Tastați `/graphify` în asistentul AI de programare, iar acesta vă mapează întregul proiect (cod, documentație, PDF-uri, imagini, videoclipuri) într-un **graf de cunoștințe** pe care îl puteți **interoga în loc să faceți grep** prin fișiere.

- **Maparea codului gratuit, complet local.** Codul este analizat cu tree-sitter AST: determinist, fără LLM, nimic nu părăsește mașina voastră. (Documentația, PDF-urile, imaginile și videoclipurile folosesc modelul asistentului vostru sau o cheie API configurată pentru o trecere semantică.)
- **Fiecare muchie este explicată.** Fiecare conexiune este etichetată `EXTRACTED` (explicită în sursă) sau `INFERRED` (rezolvată de graphify), astfel încât puteți distinge ce a fost citit direct de ce a fost dedus.
- **Nu este un index vectorial.** Fără embeddings, fără stocare vectorială: un graf real pe care îl parcurgeți. Puneți o întrebare, trasați calea dintre două lucruri sau explicați un concept.

```bash
uv tool install graphifyy      # install the CLI (or: pipx install graphifyy)
graphify install               # register the skill with your AI assistant
```

Apoi, în asistentul vostru AI:

```
/graphify .
```

Asta e tot. Obțineți **trei fișiere**:

```
graphify-out/
├── graph.html       open in any browser — click nodes, filter, search
├── GRAPH_REPORT.md  the highlights: key concepts, surprising connections, suggested questions
└── graph.json       the full graph — query it anytime without re-reading your files
```

Graful persistat include `graph.schema_version` astfel încât integrările să poată detecta
modificările de format incompatibile, plus `graph.graphify_version` care identifică
versiunea Graphify care l-a produs.

## Vedeți-l în acțiune

<p align="center">
  <img src="https://raw.githubusercontent.com/Graphify-Labs/graphify/v8/docs/demo-path.svg" alt="graphify path query: a terminal asks for the shortest path between FastAPI and ModelField, and the answer lights up hop by hop across the knowledge graph" width="900">
</p>

Odată ce graful este construit, îl interogați în loc să citiți fișiere. Rezultat real, graphify rulat pe baza de cod FastAPI prezentată mai sus:

```text
$ graphify explain "APIRouter"
Node: APIRouter
  Source:    routing.py L2210
  Community: 2
  Degree:    47

Connections (47):
  --> RequestValidationError [uses] [INFERRED]
  --> Dependant [uses] [INFERRED]
  --> .get() [method] [EXTRACTED]
  <-- __init__.py [imports] [EXTRACTED]
  ...

$ graphify path "FastAPI" "ModelField"
Shortest path (3 hops):
  FastAPI --uses--> DefaultPlaceholder <--references-- get_request_handler() --references--> ModelField
```

Fiecare muchie poartă o **etichetă de încredere** (`EXTRACTED` = explicită în sursă, `INFERRED` = derivată prin rezolvare), astfel încât puteți distinge ce a fost citit direct de ce a fost dedus. `graphify query "<question>"` returnează un subgraf delimitat pentru o întrebare în limbaj natural, iar `graphify path A B` trasează modul în care se conectează oricare două lucruri.

## Install

> [!IMPORTANT]
> **Pachet oficial:** Pachetul PyPI este `graphifyy` (dublu-y). Alte pachete `graphify*` de pe PyPI nu sunt afiliate. Comanda CLI rămâne `graphify`.

Depozitul sursă oficial este [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify).

**Pasul 1 — instalați pachetul:**

```bash
# Recommended (isolated env; if 'graphify' isn't found after, run: uv tool update-shell):
uv tool install graphifyy

# Alternatives:
pipx install graphifyy
pip install graphifyy  # may need PATH setup — see note below
```

**Pasul 2 — înregistrați skill-ul la asistentul vostru AI:**

```bash
graphify install
```

Asta e tot. Deschideți asistentul AI și tastați `/graphify .`

Pentru a instala skill-ul asistentului în depozitul curent în loc de profilul
vostru de utilizator, adăugați `--project`:

```bash
graphify install --project
graphify install --project --platform codex
```

Instalările la nivel de proiect scriu în directorul curent, de exemplu
`.claude/skills/graphify/SKILL.md` sau `.agents/skills/graphify/SKILL.md` (plus un
sidecar `references/` pe care skill-ul îl încarcă la cerere), și
afișează un indiciu `git add` pentru fișierele care pot fi comise.
Comenzile per platformă care acceptă instalări la nivel de proiect acceptă aceeași opțiune,
de exemplu `graphify claude install --project` sau `graphify codex install --project`.

> [!TIP]
> Întâmpinați `command not found`, o problemă `pip`-pe-Mac/Windows, citarea PowerShell, utilizarea `uvx`, ciudățenii PATH la git-hook sau modul strict? Vedeți **[Instalare](https://docs.graphify.com/installation)** și **[Depanare](https://docs.graphify.com/troubleshooting)**.

## Faceți asistentul să folosească mereu graful

Rulați asta o dată în proiectul vostru după construirea unui graf:

Rulați `graphify <platform> install` o dată în proiectul vostru, de exemplu `graphify claude install` sau `graphify codex install` (sau `graphify install --platform <name>`).

Asta scrie un mic fișier de configurare care îi spune asistentului vostru să consulte graful de cunoștințe pentru întrebări despre baza de cod, preferând interogări delimitate precum `graphify query "<question>"` în locul citirii raportului complet sau al grep-ului prin fișiere brute.

- **Platforme cu hook-uri** (Claude Code, Gemini CLI): un hook se declanșează automat înaintea apelurilor de unelte de tip căutare (și, pe Claude Code, înainte de citirea fișierelor sursă unul câte unul prin uneltele Read/Glob) și împinge asistentul către calea grafului.
- **Platforme cu fișiere de instrucțiuni** (Codex, OpenCode, Cursor etc.): fișierele de instrucțiuni persistente (`AGENTS.md`, `.cursor/rules/` etc.) oferă aceeași îndrumare „întâi interogarea”.

`GRAPH_REPORT.md` este în continuare disponibil pentru revizuirea amplă a arhitecturii.

**CodeBuddy** face aceleași două lucruri ca și Claude Code: scrie o secțiune `CODEBUDDY.md` care îi spune CodeBuddy să citească `graphify-out/GRAPH_REPORT.md` înainte de a răspunde la întrebări despre arhitectură, și instalează hook-uri `PreToolUse` (`.codebuddy/settings.json`) care se declanșează înaintea comenzilor de căutare Bash și a citirilor de fișiere, împingând în schimb către `graphify query`.

**Codex** scrie în `AGENTS.md`, care este ceea ce poartă efectiv îndrumarea mereu activă a grafului pe această platformă. `graphify codex install` înregistrează și un hook `PreToolUse` în `.codex/hooks.json` (`graphify hook-check`), dar acea intrare este în mod deliberat un **no-op**: Codex Desktop respinge `hookSpecificOutput.additionalContext` pe `PreToolUse`, așa că emiterea unei împingeri acolo ar strica apelurile uneltei Bash. Spre deosebire de Claude Code, unde hook-ul (`graphify hook-guard`) face împingerea, pe Codex hook-ul se declanșează și nu face nimic în mod intenționat, iar `AGENTS.md` este mecanismul mereu activ.

**Kilo Code** instalează skill-ul Graphify în `~/.config/kilo/skills/graphify/SKILL.md` și o comandă nativă `/graphify` în `~/.config/kilo/command/graphify.md`. `graphify kilo install` scrie și `AGENTS.md`, plus un plugin nativ `tool.execute.before` (`.kilo/plugins/graphify.js` + înregistrarea `.kilo/kilo.json` sau `.kilo/kilo.jsonc`), astfel încât Kilo primește același comportament de reamintire mereu activă a grafului prin configurarea nativă `.kilo`.

**Cursor** scrie `.cursor/rules/graphify.mdc` cu `alwaysApply: true`, astfel încât Cursor îl include automat în fiecare conversație, fără hook necesar.

Pentru a elimina graphify de pe toate platformele deodată: `graphify uninstall` (adăugați `--purge` pentru a șterge și `graphify-out/`). Sau folosiți comanda per platformă (de ex. `graphify claude uninstall`).

## Ce fișiere gestionează

graphify analizează ~40 de limbaje de programare local cu tree-sitter AST și mapează documentația, PDF-urile, imaginile și audio/video printr-o trecere semantică opțională. Lista completă: **[Intrări acceptate](https://docs.graphify.com/concepts/supported-inputs)**.

## Comenzi uzuale

```bash
/graphify .                        # build graph for current folder
/graphify ./docs --update          # re-extract only changed files
/graphify . --cluster-only         # rerun clustering without re-extracting
/graphify . --cluster-only --resolution 1.5      # more granular communities
/graphify . --cluster-only --exclude-hubs 99     # suppress utility super-hubs from god-node rankings
/graphify . --no-viz               # skip the HTML, just the report + JSON
/graphify . --wiki                 # build a markdown wiki from the graph
graphify export callflow-html      # Mermaid architecture/call-flow HTML (auto-regenerates on every git commit if hook is installed)

/graphify query "what connects auth to the database?"
/graphify path "UserService" "DatabasePool"
/graphify explain "RateLimiter"

/graphify add https://arxiv.org/abs/1706.03762   # fetch a paper and add it
/graphify add <youtube-url>                       # transcribe and add a video

graphify hook install              # auto-rebuild on commit + branch checkout (run `graphify update .` after `git pull` — see "Recommended workflow" below)
graphify merge-graphs a.json b.json              # combine two graphs

graphify prs                       # PR dashboard: CI state, review status, worktree mapping
graphify prs 42                    # deep dive on PR #42 with graph impact
graphify prs --triage              # AI ranks your review queue (uses whatever backend is configured)
graphify prs --conflicts           # PRs sharing graph communities — merge-order risk
```

Vedeți [referința completă a comenzilor](#full-command-reference) mai jos.

## Confidențialitate

- **Fișiere de cod** — procesate local prin tree-sitter. Nimic nu părăsește mașina voastră. Un corpus format doar din cod nu necesită cheie API — `graphify extract` rulează complet offline. Pe un repo mixt, adăugați `--code-only` pentru a indexa doar codul și a sări peste documentele/PDF-urile/imaginile care altfel ar avea nevoie de un LLM.
- **Video / audio** — transcrise local cu faster-whisper. Nimic nu părăsește mașina voastră.
- **Documente, PDF-uri, imagini** — trimise asistentului vostru AI pentru extracție semantică (prin skill-ul `/graphify`, folosind orice model rulează sesiunea voastră IDE). `graphify extract` în mod headless necesită `GEMINI_API_KEY` / `GOOGLE_API_KEY` (Gemini), `MOONSHOT_API_KEY` (Kimi), `ANTHROPIC_API_KEY` (Claude), `OPENAI_API_KEY` (OpenAI), `DEEPSEEK_API_KEY` (DeepSeek), o instanță Ollama în funcțiune (`OLLAMA_BASE_URL`), credențiale AWS prin lanțul standard de furnizori (Bedrock – nu e nevoie de cheie API, folosește IAM), sau binarul CLI `claude` (Claude Code – nu e nevoie de cheie API, folosește abonamentul vostru Claude). Opțiunea `--dedup-llm` folosește aceeași cheie.
- **Rezidența datelor** — `graphify extract` detectează automat ce furnizor să folosească pe baza cheii API setate (prioritate: Gemini → Kimi → Claude → OpenAI → DeepSeek → Azure → Bedrock → Ollama). Pentru cod cu cerințe de rezidență a datelor, folosiți `--backend ollama` (complet local) sau transmiteți o opțiune `--backend` explicită. Kimi (`MOONSHOT_API_KEY`) rutează către serverele Moonshot AI din China.
- **Fără telemetrie**, fără urmărirea utilizării, fără analitică.
- **Jurnalizarea interogărilor** — fiecare apel `graphify query`, `graphify path`, `graphify explain` și MCP `query_graph` este jurnalizat în `~/.cache/graphify-queries.log` în format JSON Lines (marcaj de timp, întrebare, corpus, noduri returnate, durată). Răspunsurile complete de subgraf **nu** sunt stocate în mod implicit. Setați `GRAPHIFY_QUERY_LOG_DISABLE=1` pentru a renunța, sau `GRAPHIFY_QUERY_LOG=/dev/null` pentru a reduce la tăcere fără a dezactiva calea de cod.

## Graphify Cloud

[**Graphify Cloud**](https://app.graphify.com/login) este stratul mereu activ construit deasupra graphify. În loc de un graf pe care îl reconstruiți la cerere pentru fiecare folder, menține un singur graf viu pe tot parcursul ciclului vostru de dezvoltare software:

- **Cu 80% mai puține token-uri** — memoria mereu activă înseamnă că agenții voștri nu mai recitesc și reexplică baza de cod la fiecare sesiune.
- **Monorepo și între repo-uri** — un singur graf conectat peste fiecare serviciu și repozitoriu, nu un graf per folder.
- **Verificare formală** — verificați invarianții arhitecturali și de dependențe față de graful viu.
- **Revizuire de cod cu o vedere de ansamblu asupra SDLC-ului** — vedeți cum se propagă o modificare prin întregul sistem înainte de a face merge.
- **Conectori SDLC** — aduceți Sentry, Jira și altele, astfel încât incidentele, tichetele și codul să trăiască într-un singur graf.
- **Mereu activ** — se actualizează continuu în fundal peste cod, documente și întâlniri.

**[Începeți o perioadă de probă gratuită de 14 zile pe app.graphify.com &rarr;](https://app.graphify.com/login)**
