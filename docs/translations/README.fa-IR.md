در دستیار کدنویسی هوش مصنوعی خود `/graphify` را تایپ کنید تا کل پروژهٔ شما (کد، مستندات، فایل‌های PDF، تصاویر، ویدیوها) را به یک **گراف دانش** نگاشت کند که می‌توانید به‌جای grep کردن در فایل‌ها **از آن پرس‌وجو کنید**.

- **نگاشت کد رایگان و کاملاً محلی.** کد با درخت نحو انتزاعی (AST) tree-sitter تجزیه می‌شود: قطعی، بدون مدل زبانی، و هیچ‌چیز از دستگاه شما خارج نمی‌شود. (مستندات، فایل‌های PDF، تصاویر و ویدیو برای یک گذر معنایی از مدل دستیار شما یا یک کلید API پیکربندی‌شده استفاده می‌کنند.)
- **هر یال توضیح داده می‌شود.** هر اتصال با `EXTRACTED` (صریح در منبع) یا `INFERRED` (برطرف‌شده توسط graphify) برچسب می‌خورد، تا بتوانید آنچه را مستقیماً خوانده شده از آنچه استنتاج شده تشخیص دهید.
- **یک نمایهٔ برداری نیست.** بدون تعبیه‌ها، بدون انبار برداری: یک گراف واقعی که آن را پیمایش می‌کنید. سؤالی بپرسید، مسیر میان دو چیز را ردیابی کنید، یا یک مفهوم را توضیح دهید.

> [!NOTE]
> **این را همیشه‌روشن می‌خواهید؟** [Graphify Cloud](https://app.graphify.com/login) گراف را در سراسر چرخهٔ عمر توسعهٔ نرم‌افزار شما زنده نگه می‌دارد: پشتیبانی از مونوریپو و چند-مخزنی، وارسی صوری، و بازبینی کد با نگاهی از بالا به کل SDLC شما، به‌علاوهٔ اتصال‌دهنده‌هایی برای Sentry و Jira و موارد دیگر، تا رخدادها و تیکت‌ها در همان گرافی قرار گیرند که کد شما در آن است. **[یک دورهٔ آزمایشی رایگان ۱۴ روزه را در app.graphify.com آغاز کنید](https://app.graphify.com/login)**.

**شروع کنید** (۳۰ ثانیه):

```bash
uv tool install graphifyy      # install the CLI (or: pipx install graphifyy)
graphify install               # register the skill with your AI assistant
```

سپس، در دستیار هوش مصنوعی خود:

```
/graphify .
```

همین. شما **سه فایل** دریافت می‌کنید:

```
graphify-out/
├── graph.html       open in any browser — click nodes, filter, search
├── GRAPH_REPORT.md  the highlights: key concepts, surprising connections, suggested questions
└── graph.json       the full graph — query it anytime without re-reading your files
```

گراف ذخیره‌شده شامل `graph.schema_version` است تا یکپارچه‌سازی‌ها بتوانند
تغییرات ناسازگار قالب را تشخیص دهند، به‌علاوهٔ `graph.graphify_version` که
نسخهٔ Graphify تولیدکنندهٔ آن را مشخص می‌کند.

**کار می‌کند در** Claude Code، Cursor، Codex، Gemini CLI، GitHub Copilot و ۱۵+ مورد دیگر — [پلتفرم خود را انتخاب کنید](#install).

## See it in action

<p align="center">
  <img src="https://raw.githubusercontent.com/Graphify-Labs/graphify/v8/docs/demo-path.svg" alt="graphify path query: a terminal asks for the shortest path between FastAPI and ModelField, and the answer lights up hop by hop across the knowledge graph" width="900">
</p>

پس از ساخت گراف، به‌جای خواندن فایل‌ها از آن پرس‌وجو می‌کنید. خروجی واقعی، اجرای graphify روی کدبیس FastAPI که در بالا نشان داده شد:

```text
$ graphify explain "APIRouter"
Node: APIRouter
  Source:    routing.py L2210
  Community: 2
  Degree:    47

Connections (47):
  --> RequestValidationError [uses] [INFERRED]
  --> Dependant [uses] [INFERRED]
  --> .get() [method] [EXTRACTED]
  <-- __init__.py [imports] [EXTRACTED]
  ...

$ graphify path "FastAPI" "ModelField"
Shortest path (3 hops):
  FastAPI --uses--> DefaultPlaceholder <--references-- get_request_handler() --references--> ModelField
```

هر یال یک **برچسب اطمینان** حمل می‌کند (`EXTRACTED` = صریح در منبع، `INFERRED` = مشتق‌شده از طریق برطرف‌سازی)، تا بتوانید آنچه را مستقیماً خوانده شده از آنچه استنتاج شده تشخیص دهید. `graphify query "<question>"` یک زیرگراف محدودشده برای یک سؤال به زبان ساده بازمی‌گرداند، و `graphify path A B` ردیابی می‌کند که هر دو چیز چگونه به هم متصل می‌شوند.

## What it does

آنچه به‌صورت آماده دریافت می‌کنید:

| Capability | What you get |
|---|---|
| **گره‌های خدا** | پرارتباط‌ترین مفاهیم، تا ببینید همه‌چیز از میان چه چیزی جریان می‌یابد |
| **جامعه‌ها** | گراف تقسیم‌شده به زیرسیستم‌ها (Leiden)، با برچسب‌های بدون مدل زبانی |
| **پیوندهای میان‌فایلی** | `calls` / `imports` / `inherits` / `mixes_in` برطرف‌شده در حدود ۴۰ زبان از طریق AST tree-sitter |
| **پرس‌وجو، مسیر، توضیح** | سؤالی بپرسید، مسیر میان دو چیز را ردیابی کنید، یا یک مفهوم را توضیح دهید، همه در برابر `graph.json` |
| **منطق + ارجاع‌های مستند** | توضیحات `# NOTE:` / `# WHY:` و استنادهای ADR/RFC به گره‌های درجه‌یک پیوندخورده به کد تبدیل می‌شوند |
| **فراتر از کد** | مستندات، فایل‌های PDF، تصاویر و ویدیو/صوت همگی در همان گراف نگاشت می‌شوند |
| **محلی‌محور** | کد به‌صورت محلی با tree-sitter تجزیه می‌شود (بدون مدل زبانی، هیچ‌چیز از دستگاه شما خارج نمی‌شود)؛ تنها گذر معنایی روی مستندات/رسانه یک بک‌اند را فرا می‌خواند، و فقط اگر شما یکی را پیکربندی کنید |

> [!TIP]
> این را در مخازن بسیار یا یک مونوریپو اجرا می‌کنید؟ [Graphify Cloud](https://app.graphify.com/login) این کار را به‌طور پیوسته انجام می‌دهد و هزینهٔ توکن عامل را ۸۰٪ کاهش می‌دهد، با پیوندهای چند-مخزنی، بازبینی کد در گسترهٔ SDLC، وارسی صوری، و اتصال‌دهنده‌های Sentry/Jira. [یک دورهٔ آزمایشی رایگان ۱۴ روزه را آغاز کنید &rarr;](https://app.graphify.com/login)

## Install

> [!IMPORTANT]
> **بستهٔ رسمی:** بستهٔ PyPI همان `graphifyy` است (با دو y). دیگر بسته‌های `graphify*` روی PyPI وابسته به ما نیستند. فرمان CLI همچنان `graphify` است.

مخزن منبع رسمی [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) است.

**گام ۱ — بسته را نصب کنید:**

```bash
# Recommended (isolated env; if 'graphify' isn't found after, run: uv tool update-shell):
uv tool install graphifyy

# Alternatives:
pipx install graphifyy
pip install graphifyy  # may need PATH setup — see note below
```

**گام ۲ — مهارت را در دستیار هوش مصنوعی خود ثبت کنید:**

```bash
graphify install
```

همین. دستیار هوش مصنوعی خود را باز کنید و `/graphify .` را تایپ کنید

برای نصب مهارت دستیار در مخزن کنونی به‌جای نمایهٔ کاربری
خود، `--project` را اضافه کنید:

```bash
graphify install --project
graphify install --project --platform codex
```

نصب‌های محدودشده به پروژه زیر دایرکتوری کنونی نوشته می‌شوند، برای مثال
`.claude/skills/graphify/SKILL.md` یا `.agents/skills/graphify/SKILL.md` (به‌علاوهٔ یک
جانبی `references/` که مهارت بنا به تقاضا بارگذاری می‌کند)، و
یک راهنمای `git add` را برای فایل‌هایی که می‌توان کامیت کرد چاپ می‌کنند.
فرمان‌های هر پلتفرم که از نصب‌های محدودشده به پروژه پشتیبانی می‌کنند همان پرچم را می‌پذیرند،
برای مثال `graphify claude install --project` یا `graphify codex install --project`.

> [!TIP]
> با `command not found`، یک مشکل `pip` روی Mac/Windows، نقل‌قول‌گذاری PowerShell، استفاده از `uvx`، ویژگی‌های خاص PATH در git-hook، یا حالت سخت‌گیرانه برخورد می‌کنید؟ به **[Installation](https://docs.graphify.com/installation)** و **[Troubleshooting](https://docs.graphify.com/troubleshooting)** مراجعه کنید.

## Make your assistant always use the graph

این را یک بار در پروژهٔ خود پس از ساخت یک گراف اجرا کنید:

`graphify <platform> install` را یک بار در پروژهٔ خود اجرا کنید، برای مثال `graphify claude install` یا `graphify codex install` (یا `graphify install --platform <name>`).

این یک فایل پیکربندی کوچک می‌نویسد که به دستیار شما می‌گوید برای پرسش‌های مربوط به کدبیس به گراف دانش رجوع کند و پرس‌وجوهای محدودشده مانند `graphify query "<question>"` را بر خواندن کل گزارش یا grep کردن فایل‌های خام ترجیح دهد.

- **پلتفرم‌های قلاب** (Claude Code، Gemini CLI): یک قلاب به‌طور خودکار پیش از فراخوان‌های ابزار سبک-جست‌وجو (و در Claude Code، پیش از خواندن فایل‌های منبع یک‌به‌یک از طریق ابزارهای Read/Glob) فعال می‌شود و دستیار شما را به‌سوی مسیر گراف هدایت می‌کند.
- **پلتفرم‌های فایل-دستورالعمل** (Codex، OpenCode، Cursor و غیره): فایل‌های دستورالعمل پایدار (`AGENTS.md`، `.cursor/rules/` و غیره) همان راهنمایی پرس‌وجو-نخست را فراهم می‌کنند.

`GRAPH_REPORT.md` همچنان برای بازبینی گستردهٔ معماری در دسترس است.

**CodeBuddy** همان دو کاری را که Claude Code انجام می‌دهد انجام می‌دهد: یک بخش `CODEBUDDY.md` می‌نویسد که به CodeBuddy می‌گوید پیش از پاسخ به پرسش‌های معماری `graphify-out/GRAPH_REPORT.md` را بخواند، و قلاب‌های `PreToolUse` (`.codebuddy/settings.json`) را نصب می‌کند که پیش از فرمان‌های جست‌وجوی Bash و خواندن فایل‌ها فعال می‌شوند و به‌جای آن به‌سوی `graphify query` هدایت می‌کنند.

**Codex** در `AGENTS.md` می‌نویسد، که همان چیزی است که در عمل راهنمایی همیشه‌روشن گراف را روی این پلتفرم حمل می‌کند. `graphify codex install` همچنین یک قلاب `PreToolUse` را در `.codex/hooks.json` (`graphify hook-check`) ثبت می‌کند، اما آن ورودی عامدانه یک **عمل بی‌اثر** است: Codex Desktop `hookSpecificOutput.additionalContext` را روی `PreToolUse` رد می‌کند، بنابراین انتشار یک هدایت در آنجا فراخوان‌های ابزار Bash را خراب می‌کند. برخلاف Claude Code، که در آن قلاب (`graphify hook-guard`) هدایت را انجام می‌دهد، در Codex قلاب فعال می‌شود و عمداً کاری انجام نمی‌دهد، و `AGENTS.md` سازوکار همیشه‌روشن است.

**Kilo Code** مهارت Graphify را در `~/.config/kilo/skills/graphify/SKILL.md` و یک فرمان بومی `/graphify` را در `~/.config/kilo/command/graphify.md` نصب می‌کند. `graphify kilo install` همچنین `AGENTS.md` را به‌علاوهٔ یک افزونهٔ بومی `tool.execute.before` (`.kilo/plugins/graphify.js` + ثبت `.kilo/kilo.json` یا `.kilo/kilo.jsonc`) می‌نویسد تا Kilo از طریق پیکربندی بومی `.kilo` همان رفتار یادآوری همیشه‌روشن گراف را دریافت کند.

**Cursor** فایل `.cursor/rules/graphify.mdc` را با `alwaysApply: true` می‌نویسد، بنابراین Cursor آن را به‌طور خودکار در هر گفت‌وگو می‌گنجاند، بدون نیاز به قلاب.

برای حذف graphify از همهٔ پلتفرم‌ها به‌یک‌باره: `graphify uninstall` (برای حذف `graphify-out/` نیز `--purge` را اضافه کنید). یا از فرمان هر پلتفرم استفاده کنید (برای مثال `graphify claude uninstall`).

## Common commands

```bash
/graphify .                        # build graph for current folder
/graphify ./docs --update          # re-extract only changed files
/graphify . --cluster-only         # rerun clustering without re-extracting
/graphify . --cluster-only --resolution 1.5      # more granular communities
/graphify . --cluster-only --exclude-hubs 99     # suppress utility super-hubs from god-node rankings
/graphify . --no-viz               # skip the HTML, just the report + JSON
/graphify . --wiki                 # build a markdown wiki from the graph
graphify export callflow-html      # Mermaid architecture/call-flow HTML (auto-regenerates on every git commit if hook is installed)

/graphify query "what connects auth to the database?"
/graphify path "UserService" "DatabasePool"
/graphify explain "RateLimiter"

/graphify add https://arxiv.org/abs/1706.03762   # fetch a paper and add it
/graphify add <youtube-url>                       # transcribe and add a video

graphify hook install              # auto-rebuild on commit + branch checkout (run `graphify update .` after `git pull` — see "Recommended workflow" below)
graphify merge-graphs a.json b.json              # combine two graphs

graphify prs                       # PR dashboard: CI state, review status, worktree mapping
graphify prs 42                    # deep dive on PR #42 with graph impact
graphify prs --triage              # AI ranks your review queue (uses whatever backend is configured)
graphify prs --conflicts           # PRs sharing graph communities — merge-order risk
```

## Privacy

- **فایل‌های کد** — به‌صورت محلی از طریق tree-sitter پردازش می‌شوند. هیچ‌چیز از دستگاه شما خارج نمی‌شود. یک پیکرهٔ تنها-کد به هیچ کلید API نیاز ندارد — `graphify extract` کاملاً آفلاین اجرا می‌شود. روی یک مخزن ترکیبی، `--code-only` را اضافه کنید تا فقط کد را نمایه کنید و از مستندات/فایل‌های PDF/تصاویری که در غیر این صورت به یک مدل زبانی نیاز دارند صرف‌نظر کنید.
- **ویدیو / صوت** — به‌صورت محلی با faster-whisper رونویسی می‌شود. هیچ‌چیز از دستگاه شما خارج نمی‌شود.
- **مستندات، فایل‌های PDF، تصاویر** — برای استخراج معنایی به دستیار هوش مصنوعی شما ارسال می‌شوند (از طریق مهارت `/graphify`، با استفاده از هر مدلی که نشست IDE شما اجرا می‌کند). `graphify extract` بدون‌واسط به `GEMINI_API_KEY` / `GOOGLE_API_KEY` (Gemini)، `MOONSHOT_API_KEY` (Kimi)، `ANTHROPIC_API_KEY` (Claude)، `OPENAI_API_KEY` (OpenAI)، `DEEPSEEK_API_KEY` (DeepSeek)، یک نمونهٔ در حال اجرای Ollama (`OLLAMA_BASE_URL`)، اعتبارنامه‌های AWS از طریق زنجیرهٔ استاندارد ارائه‌دهنده (Bedrock - بدون نیاز به کلید API، از IAM استفاده می‌کند)، یا باینری `claude` CLI (Claude Code - بدون نیاز به کلید API، از اشتراک Claude شما استفاده می‌کند) نیاز دارد. پرچم `--dedup-llm` از همان کلید استفاده می‌کند.
- **اقامتگاه داده** — `graphify extract` به‌طور خودکار بر اساس کلید API تنظیم‌شده تشخیص می‌دهد از کدام ارائه‌دهنده استفاده کند (اولویت: Gemini → Kimi → Claude → OpenAI → DeepSeek → Azure → Bedrock → Ollama). برای کدی با الزامات اقامتگاه داده، از `--backend ollama` (کاملاً محلی) استفاده کنید یا یک پرچم `--backend` صریح بدهید. Kimi (`MOONSHOT_API_KEY`) به سرورهای Moonshot AI در چین مسیریابی می‌کند.
- **بدون سنجش از راه دور**، بدون ردیابی استفاده، بدون تحلیل.
- **ثبت پرس‌وجو** — هر فراخوان `graphify query`، `graphify path`، `graphify explain` و MCP `query_graph` در `~/.cache/graphify-queries.log` با قالب JSON Lines ثبت می‌شود (برچسب زمانی، سؤال، پیکره، گره‌های بازگردانده‌شده، مدت). پاسخ‌های کامل زیرگراف به‌طور پیش‌فرض ذخیره **نمی‌شوند**. برای انصراف `GRAPHIFY_QUERY_LOG_DISABLE=1` را تنظیم کنید، یا `GRAPHIFY_QUERY_LOG=/dev/null` را برای خاموش کردن بدون غیرفعال کردن مسیر کد.

## Graphify Cloud

[**Graphify Cloud**](https://app.graphify.com/login) لایهٔ همیشه‌روشنی است که بر فراز graphify ساخته شده است. به‌جای گرافی که بنا به تقاضا برای هر پوشه بازسازی می‌کنید، یک گراف زندهٔ واحد را در سراسر چرخهٔ عمر توسعهٔ نرم‌افزار شما نگه می‌دارد:

- **۸۰٪ توکن کمتر** — حافظهٔ همیشه‌روشن یعنی عامل‌های شما در هر نشست از بازخواندن و بازتوضیح کدبیس دست می‌کشند.

- **وارسی صوری** — ناوردایی‌های معماری و وابستگی را در برابر گراف زنده بررسی کنید.
- **بازبینی کد با نگاهی از بالا به SDLC شما** — ببینید چگونه یک تغییر در کل سیستم موج می‌اندازد پیش از آنکه ادغام کنید.
- **اتصال‌دهنده‌های SDLC** — Sentry، Jira و موارد دیگر را وارد کنید، تا رخدادها، تیکت‌ها و کد در یک گراف زندگی کنند.
- **همیشه‌روشن** — به‌طور پیوسته در پس‌زمینه در سراسر کد، مستندات و جلسات به‌روزرسانی می‌شود.
