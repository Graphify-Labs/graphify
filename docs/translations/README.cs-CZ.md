Napište `/graphify` ve svém asistentovi pro psaní kódu s AI a ten zmapuje celý váš projekt (kód, dokumentaci, PDF, obrázky, videa) do **znalostního grafu**, který můžete **dotazovat místo grepování** napříč soubory.

- **Mapování kódu zdarma, plně lokálně.** Kód se parsuje pomocí tree-sitter AST: deterministicky, bez LLM, nic neopustí váš počítač. (Dokumentace, PDF, obrázky a video využívají model vašeho asistenta nebo nakonfigurovaný API klíč pro sémantický průchod.)
- **Každá hrana je vysvětlena.** Každé spojení je označeno `EXTRACTED` (explicitně ve zdroji) nebo `INFERRED` (odvozeno nástrojem graphify), takže rozlišíte, co bylo přečteno přímo, od toho, co bylo odvozeno.
- **Není to vektorový index.** Žádné embeddingy, žádné vektorové úložiště: skutečný graf, kterým procházíte. Položte otázku, vysledujte cestu mezi dvěma věcmi nebo nechte vysvětlit jeden koncept.

nekompatibilní změny formátu, plus `graph.graphify_version` identifikující
vydání Graphify, které jej vytvořilo.

## Podívejte se na to v akci

<p align="center">
  <img src="https://raw.githubusercontent.com/Graphify-Labs/graphify/v8/docs/demo-path.svg" alt="graphify path query: a terminal asks for the shortest path between FastAPI and ModelField, and the answer lights up hop by hop across the knowledge graph" width="900">
</p>

Jakmile je graf sestaven, dotazujete jej místo čtení souborů. Skutečný výstup, graphify spuštěný na výše zobrazené kódové základně FastAPI:

```text
$ graphify explain "APIRouter"
Node: APIRouter
  Source:    routing.py L2210
  Community: 2
  Degree:    47

Connections (47):
  --> RequestValidationError [uses] [INFERRED]
  --> Dependant [uses] [INFERRED]
  --> .get() [method] [EXTRACTED]
  <-- __init__.py [imports] [EXTRACTED]
  ...

$ graphify path "FastAPI" "ModelField"
Shortest path (3 hops):
  FastAPI --uses--> DefaultPlaceholder <--references-- get_request_handler() --references--> ModelField
```

Každá hrana nese **značku spolehlivosti** (`EXTRACTED` = explicitně ve zdroji, `INFERRED` = odvozeno rozlišením), takže rozlišíte, co bylo přečteno přímo, od toho, co bylo odvozeno. `graphify query "<question>"` vrátí ohraničený podgraf pro otázku v běžném jazyce a `graphify path A B` vysleduje, jak jsou libovolné dvě věci propojeny.

## Co to umí

Co dostanete rovnou z krabice:

| Schopnost | Co dostanete |
|---|---|
| **Boží uzly (god nodes)** | Nejvíce propojené koncepty, takže vidíte, čím vše protéká |
| **Komunity** | Graf rozdělený na subsystémy (Leiden), s popisky bez LLM |
| **Propojení napříč soubory** | `calls` / `imports` / `inherits` / `mixes_in` vyřešené napříč ~40 jazyky pomocí tree-sitter AST |
| **Dotaz, cesta, vysvětlení** | Položte otázku, vysledujte cestu mezi dvěma věcmi nebo vysvětlete jeden koncept, vše proti `graph.json` |
| **Zdůvodnění + odkazy na dokumentaci** | Komentáře `# NOTE:` / `# WHY:` a citace ADR/RFC se stávají prvotřídními uzly propojenými s kódem |
| **Za hranicí kódu** | Dokumentace, PDF, obrázky a video/audio se mapují do stejného grafu |
| **Lokálně především** | Kód se parsuje lokálně pomocí tree-sitter (bez LLM, nic neopustí váš počítač); pouze sémantický průchod přes dokumentaci/média volá backend, a to jen pokud nějaký nakonfigurujete |

## Install

> [!IMPORTANT]
> **Oficiální balíček:** Balíček na PyPI je `graphifyy` (dvojité y). Ostatní balíčky `graphify*` na PyPI nejsou nijak spřízněné. Příkaz CLI je stále `graphify`.

Oficiální zdrojový repozitář je [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify).

**Krok 1 — nainstalujte balíček:**

```bash
# Recommended (isolated env; if 'graphify' isn't found after, run: uv tool update-shell):
uv tool install graphifyy

# Alternatives:
pipx install graphifyy
pip install graphifyy  # may need PATH setup — see note below
```

**Krok 2 — zaregistrujte skill u svého AI asistenta:**

```bash
graphify install
```

A je to. Otevřete svého AI asistenta a napište `/graphify .`

Chcete-li nainstalovat skill asistenta do aktuálního repozitáře místo do vašeho
uživatelského profilu, přidejte `--project`:

```bash
graphify install --project
graphify install --project --platform codex
```

Instalace v rámci projektu zapisují do aktuálního adresáře, například
`.claude/skills/graphify/SKILL.md` nebo `.agents/skills/graphify/SKILL.md` (plus
sidecar `references/`, který skill načítá na vyžádání), a
vypíšou nápovědu `git add` pro soubory, které lze commitnout.
Příkazy pro jednotlivé platformy, které podporují instalace v rámci projektu, přijímají stejný přepínač,
například `graphify claude install --project` nebo `graphify codex install --project`.

> [!TIP]
> Narážíte na `command not found`, problém s `pip` na Macu/Windows, uvozování v PowerShellu, použití `uvx`, zvláštnosti PATH git hooků nebo striktní režim? Viz **[Instalace](https://docs.graphify.com/installation)** a **[Řešení potíží](https://docs.graphify.com/troubleshooting)**.

## Přimějte svého asistenta, aby graf používal vždy

Spusťte toto jednou ve svém projektu po sestavení grafu:

Spusťte `graphify <platform> install` jednou ve svém projektu, například `graphify claude install` nebo `graphify codex install` (nebo `graphify install --platform <name>`).

Tím se zapíše malý konfigurační soubor, který řekne vašemu asistentovi, aby u otázek o kódové základně konzultoval znalostní graf a dával přednost ohraničeným dotazům jako `graphify query "<question>"` před čtením celého reportu nebo grepováním surových souborů.

- **Platformy s hooky** (Claude Code, Gemini CLI): hook se automaticky spustí před voláními nástrojů typu vyhledávání (a na Claude Code před čtením zdrojových souborů jeden po druhém přes nástroje Read/Glob) a nasměruje vašeho asistenta k cestě přes graf.
- **Platformy s instrukčními soubory** (Codex, OpenCode, Cursor atd.): trvalé instrukční soubory (`AGENTS.md`, `.cursor/rules/` atd.) poskytují stejné vedení "nejprve dotaz".

`GRAPH_REPORT.md` je stále k dispozici pro širokou architektonickou revizi.

**CodeBuddy** dělá totéž co Claude Code dvěma způsoby: zapisuje sekci `CODEBUDDY.md`, která říká CodeBuddy, aby před zodpovězením otázek o architektuře přečetl `graphify-out/GRAPH_REPORT.md`, a instaluje hooky `PreToolUse` (`.codebuddy/settings.json`), které se spustí před vyhledávacími příkazy Bash a čtením souborů a nasměrují místo toho k `graphify query`.

**Codex** zapisuje do `AGENTS.md`, což je to, co na této platformě skutečně nese vždy zapnuté vedení přes graf. `graphify codex install` také registruje hook `PreToolUse` v `.codex/hooks.json` (`graphify hook-check`), ale tato položka je záměrně **no-op**: Codex Desktop odmítá `hookSpecificOutput.additionalContext` na `PreToolUse`, takže vyslání pobídky by rozbilo volání nástroje Bash. Na rozdíl od Claude Code, kde nasměrování provádí hook (`graphify hook-guard`), na Codexu se hook spustí a záměrně nedělá nic, a `AGENTS.md` je vždy zapnutý mechanismus.

**Kilo Code** instaluje skill Graphify do `~/.config/kilo/skills/graphify/SKILL.md` a nativní příkaz `/graphify` do `~/.config/kilo/command/graphify.md`. `graphify kilo install` také zapisuje `AGENTS.md` plus nativní plugin `tool.execute.before` (`.kilo/plugins/graphify.js` + registrace `.kilo/kilo.json` nebo `.kilo/kilo.jsonc`), takže Kilo získá stejné chování vždy zapnuté připomínky grafu prostřednictvím nativní konfigurace `.kilo`.

**Cursor** zapisuje `.cursor/rules/graphify.mdc` s `alwaysApply: true`, takže Cursor jej automaticky zahrne do každé konverzace, bez potřeby hooku.

Chcete-li odstranit graphify ze všech platforem najednou: `graphify uninstall` (přidejte `--purge`, chcete-li také smazat `graphify-out/`). Nebo použijte příkaz pro jednotlivou platformu (např. `graphify claude uninstall`).

## Běžné příkazy

```bash
/graphify .                        # build graph for current folder
/graphify ./docs --update          # re-extract only changed files
/graphify . --cluster-only         # rerun clustering without re-extracting
/graphify . --cluster-only --resolution 1.5      # more granular communities
/graphify . --cluster-only --exclude-hubs 99     # suppress utility super-hubs from god-node rankings
/graphify . --no-viz               # skip the HTML, just the report + JSON
/graphify . --wiki                 # build a markdown wiki from the graph
graphify export callflow-html      # Mermaid architecture/call-flow HTML (auto-regenerates on every git commit if hook is installed)

/graphify query "what connects auth to the database?"
/graphify path "UserService" "DatabasePool"
/graphify explain "RateLimiter"

/graphify add https://arxiv.org/abs/1706.03762   # fetch a paper and add it
/graphify add <youtube-url>                       # transcribe and add a video

graphify hook install              # auto-rebuild on commit + branch checkout (run `graphify update .` after `git pull` — see "Recommended workflow" below)
graphify merge-graphs a.json b.json              # combine two graphs

graphify prs                       # PR dashboard: CI state, review status, worktree mapping
graphify prs 42                    # deep dive on PR #42 with graph impact
graphify prs --triage              # AI ranks your review queue (uses whatever backend is configured)
graphify prs --conflicts           # PRs sharing graph communities — merge-order risk
```

Viz [úplnou referenční příručku příkazů](#full-command-reference) níže.

## Soukromí

- **Soubory s kódem** — zpracovávány lokálně přes tree-sitter. Nic neopustí váš počítač. Korpus obsahující jen kód nevyžaduje API klíč — `graphify extract` běží plně offline. U smíšeného repozitáře přidejte `--code-only`, abyste indexovali jen kód a přeskočili dokumentaci/PDF/obrázky, které by jinak potřebovaly LLM.
- **Video / audio** — přepisováno lokálně pomocí faster-whisper. Nic neopustí váš počítač.
- **Dokumentace, PDF, obrázky** — odesílány vašemu AI asistentovi k sémantické extrakci (přes skill `/graphify`, s použitím jakéhokoli modelu, na kterém běží vaše relace IDE). Bezhlavý `graphify extract` vyžaduje `GEMINI_API_KEY` / `GOOGLE_API_KEY` (Gemini), `MOONSHOT_API_KEY` (Kimi), `ANTHROPIC_API_KEY` (Claude), `OPENAI_API_KEY` (OpenAI), `DEEPSEEK_API_KEY` (DeepSeek), běžící instanci Ollama (`OLLAMA_BASE_URL`), přihlašovací údaje AWS přes standardní řetězec poskytovatelů (Bedrock – není třeba API klíč, používá IAM) nebo binárku CLI `claude` (Claude Code – není třeba API klíč, používá vaše předplatné Claude). Přepínač `--dedup-llm` používá stejný klíč.
- **Datová rezidence** — `graphify extract` automaticky detekuje, kterého poskytovatele použít, na základě toho, který API klíč je nastaven (priorita: Gemini → Kimi → Claude → OpenAI → DeepSeek → Azure → Bedrock → Ollama). Pro kód s požadavky na datovou rezidenci použijte `--backend ollama` (plně lokální) nebo předejte explicitní přepínač `--backend`. Kimi (`MOONSHOT_API_KEY`) směruje na servery Moonshot AI v Číně.
- **Žádná telemetrie**, žádné sledování využití, žádná analytika.
- **Logování dotazů** — každé volání `graphify query`, `graphify path`, `graphify explain` a MCP `query_graph` se loguje do `~/.cache/graphify-queries.log` ve formátu JSON Lines (časová značka, otázka, korpus, vrácené uzly, doba trvání). Úplné odpovědi podgrafů **nejsou** ve výchozím nastavení ukládány. Nastavte `GRAPHIFY_QUERY_LOG_DISABLE=1` pro odhlášení nebo `GRAPHIFY_QUERY_LOG=/dev/null` pro ztišení bez zakázání kódové cesty.

## Graphify Cloud

[**Graphify Cloud**](https://app.graphify.com/login) je vždy zapnutá vrstva postavená nad graphify. Místo grafu, který znovu sestavujete na vyžádání pro jednotlivé složky, udržuje jeden živý graf napříč celým vaším životním cyklem vývoje softwaru:

- **O 80 % méně tokenů** — vždy zapnutá paměť znamená, že vaši agenti přestanou znovu číst a znovu vysvětlovat kódovou základnu každou relaci.
- **Monorepo a napříč repozitáři** — jeden propojený graf napříč každou službou a repozitářem, ne graf na složku.
- **Formální verifikace** — kontrolujte architektonické a závislostní invarianty proti živému grafu.
- **Revize kódu s ptačím pohledem na váš SDLC** — vidíte, jak se změna šíří napříč celým systémem, dříve než mergnete.
- **Konektory SDLC** — vtáhněte Sentry, Jira a další, aby incidenty, tikety a kód žily v jednom grafu.
- **Vždy zapnuté** — aktualizuje se nepřetržitě na pozadí napříč kódem, dokumentací a schůzkami.

**[Spusťte bezplatnou 14denní zkušební verzi na app.graphify.com &rarr;](https://app.graphify.com/login)**
