模块由单一入口 `__main__.py`（转发到 `gen.main`）和核心逻辑 `gen.py` 组成，依赖声明式配置 `platforms.toml`。

- 数据模型：`Platform` dataclass 解析 TOML 中每个 `[platform.<key>]` 表项，区分 `bucket=split|monolith` 两种渲染模式；`RenderedArtifact` 表示一个已渲染的 repo-relative 文件。
- 模板系统：共享核心模板位于 `fragments/core/core.md`，通过 `@@FRONTMATTER@@`、`@@INSTALL@ @@DISPATCH@@`、`@@QUERY_STUB@@`、`@@HOOKS_TARGET@@`、`@@EXTRA@@` 等占位符注入平台差异；`agents-md` hooks 使用独立的 per-host 插槽表 `_AGENTS_MD_HOOKS` 填充安装命令、标题后缀与 PreToolUse 警告。
- 引用拼装：6 个 shared 参考 + 1 个 query stub + 1 个 hooks 变体 + 可选 extraction-spec（verbose/compact），由 `reference_sources()` 按平台选择并排序输出，保证幂等。
- 校验层：`--check` 同时对比工作区已提交产物与 `expected/` 快照；`--audit-coverage` 读取 origin/v8 对应 blob，断言每宿主 v8 标题在自身 render 中唯一归属；`--schema-singleton` 断言 file_type 枚举六值统一；`--monolith-roundtrip` 对 monolith 做多集合 diff，仅允许 `_SANCTIONED_MONOLITH_DIFFS` 白名单变更；`--always-on-roundtrip` 将 always-on 块与 v8 源码中的常量逐字节比对，`ALWAYS_ON_SANCTIONED_EDITS` 记录一次性修订。
- 基线来源：所有 git 读取均通过 `_git_show(ref)` 从固定 SHA `47042beb...` 取 v8 前拆分版本，避免 HEAD 被提取 commit 污染；`_v8_available()` 探测 `origin/v8` 是否可达以给出友好提示。
- 输出路径映射：`_expected_path` 将 artifact 的 `/` 扁平化为 `__` 写入 `expected/` 顶层，规避 `.gitignore` 忽略 `skills/` 的问题。
