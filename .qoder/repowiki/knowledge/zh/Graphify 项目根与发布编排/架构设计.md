- 顶层 `pyproject.toml` 将两个子模块打包为单包 `graphifyy`：`[tool.setuptools].packages` 显式包含 `graphify`（core）与 `graphify.extractors`/`graphify.exporters`；`[project.scripts]` 暴露 `graphify`（→ `graphify.__main__:main`）和 `graphify-mcp`（→ `graphify.serve:_main`），由 core 运行时提供。
- 语言解析器全部作为 tree-sitter 可选 extras 声明在根级 `dependencies`，core 的提取器按需导入对应 `tree-sitter-*` 方言，skillgen_tool 不直接依赖它们，从而避免默认安装体积膨胀。
- `Dockerfile` 基于 `python:3.12-slim` 构建并 `pip install .[mcp]`，仅把 MCP HTTP 传输所需的 starlette/uvicorn 作为运行时镜像，graph.json 数据卷挂载而非 bake，形成「源码包 + 容器化 MCP 服务」双分发形态。
- `graphify/package-data` 中列出的 `skill*.md`、`skills/*/references/*.md`、`always_on/*.md` 正是 skillgen_tool 的渲染产物，由 build 期生成、运行期随包分发，构成 core 与 skillgen_tool 之间的契约边界。
