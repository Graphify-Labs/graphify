本模块由两部分纯 Markdown 资源组成，无可执行代码：
- `graphify/skills/<agent>/references/`：每个子目录对应一个外部 agent（agents、amp、claude、claw、codex、copilot、droid、kilo、kiro、opencode、pi、trae、vscode、windows），内含一套固定文件集（`add-watch.md`、`exports.md`、`extraction-spec.md`、`github-and-merge.md`、`hooks.md`、`query.md`、`transcribe.md`、`update.md`），按 graphify 的工作流步骤组织，作为该 agent 的 skill 参考被加载。
- `graphify/always_on/`：面向特定运行环境的常驻提示词（`agents-md.md`、`claude-md.md`、`gemini-md.md`、`kiro-steering.md`、`vscode-instructions.md`、`antigravity-rules.md`），在 agent 启动时注入，指导其优先使用 `graphify query/path/explain` 而非直接 grep 源码。
依赖方向单向：这些 Markdown 仅引用顶层 `graphify` CLI 命令（`graphify export neo4j`、`graphify benchmark`、`graphify update .` 等），不反向依赖任何 Python 实现；它们通过约定一致的 ID 命名规则（`extraction-spec.md` 中定义）和 JSON schema 与 graphify 引擎产出物对齐。
