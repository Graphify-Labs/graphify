- 每个 agent 的 references 目录采用统一文件名集合（add-watch / exports / extraction-spec / github-and-merge / hooks / query / transcribe / update），以 graphify 工作流步骤为章节标题组织内容。
- extraction-spec.md 强制要求输出严格匹配的 JSON schema，并以反引号代码块包裹完整 prompt，供外部 LLM 原样注入到子 agent 中。
- 节点 ID 必须遵循 `{repo_relative_path_stem}_{symbol}` 的小写下划线格式，禁止追加 chunk 序号，确保跨分片提取时 ID 确定性一致。
- confidence_score 取值限定离散档位（EXTRACTED=1.0、INFERRED∈{0.95,0.85,0.75,0.65,0.55}、AMBIGUOUS∈{0.1..0.3}），禁止使用 0.5 或连续值。
- source_file 字段必须逐字复制 FILE_LIST 中的绝对路径，不得重定向或简化，以保证增量更新时 replace-on-re-extract 能正确匹配已有节点。
