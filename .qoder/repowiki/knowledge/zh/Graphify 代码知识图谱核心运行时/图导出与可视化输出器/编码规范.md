- 可选第三方库（neo4j、falkordb、reflect）采用函数内 try/except ImportError 延迟导入，未安装时抛出包含 pip install 提示的明确错误。
- 用户可控字符串在进入 Cypher 语句前一律经正则白名单清洗（`_safe_rel`/`_safe_label`），进入 HTML 前经 `sanitize_label` + `html.escape` 双重转义，防止注入与 XSS。
- 节点属性过滤统一只保留 str/int/float/bool 且不以 `_` 开头的字段，并额外注入 `id` 与 `community` 键，保证数据库与可视化侧数据结构一致。
- 跨导出器共享的纯数据常量（如调色板）集中放在 `base.py`，各导出器只从该模块 import，禁止导出器之间互相引用。
