本模块按目标格式拆分为独立文件，避免与上层 `graphify/export.py` 形成循环导入：
- `base.py` 仅暴露跨导出器共享的常量（如 `COMMUNITY_COLORS`），作为唯一被其他导出器反向依赖的入口。
- `html.py` 通过 `to_html()` 生成单文件 HTML，内嵌 vis-network 9.1.6 CDN 脚本与 CSS，支持节点大小按 degree/member_count 缩放、点击信息面板、搜索框、社区复选框过滤、置信度样式边以及可选的 learning_overlay 状态环；当节点数超过 `GRAPHIFY_VIZ_NODE_LIMIT`（默认 5000）时自动退化为社区级聚合视图。
- `graphdb.py` 提供 `push_to_neo4j` 与 `push_to_falkordb` 两个函数，分别使用 `neo4j` 驱动与 `falkordb` SDK 以 OpenCypher MERGE/SET upsert 模式写入图数据库，两者共享相同的 `_safe_rel`/`_safe_label` 注入防护逻辑。
- 所有导出器都通过 `graphify.analyze._node_community_map` 把 community 映射到节点，并通过 `graphify.security.sanitize_label` 对标签做 XSS 防护；Neo4j/FalkorDB 路径在 `pip install neo4j` / `pip install falkordb` 缺失时抛出明确的 ImportError，实现可选依赖的懒加载。
