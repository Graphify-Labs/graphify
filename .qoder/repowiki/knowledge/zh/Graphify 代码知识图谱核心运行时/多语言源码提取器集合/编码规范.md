- 每个语言文件以 `"""<Lang> extractor. Moved verbatim from graphify/extract.py."""` 开头，并包含 `from __future__ import annotations`，体现 verbatim 迁移约束。
- 语言提取器统一暴露 `extract_<lang>(path: Path) -> dict` 签名，返回含 `nodes`、`edges` 及可选 `raw_calls` 的字典，错误路径返回带 `error` 键的空结果。
- 树节点文本一律通过 `base._read_text(node, source)` 从原始字节切片解码，而非直接访问 node.text，保证 UTF-8 容错。
- 节点 ID 通过 `base._make_id(...)` 生成，并在需要区分外部引用时加命名空间前缀（如 `ref_`、`go_pkg_`、`csharp_namespace:`），避免与本地代码节点碰撞。
- 类型引用收集函数遵循 `_xxx_collect_type_refs(node, source, generic, out)` 模式，递归遍历子节点并将 `(name, role)` 元组追加到 `out`，role 为 `type` 或 `generic_arg`。
- 语言内置/预声明类型通过模块级 `frozenset`（如 `_GO_PREDECLARED_TYPES`、`_JAVA_BUILTIN_TYPES`、`_KOTLIN_BUILTIN_TYPES`）过滤，防止标准库标量污染图节点。
