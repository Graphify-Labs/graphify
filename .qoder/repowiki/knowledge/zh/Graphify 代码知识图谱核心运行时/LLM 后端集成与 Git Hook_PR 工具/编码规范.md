- 后端能力通过 `BACKENDS[backend]` 字典的布尔键（如 `vision`）声明，运行时用 `_backend_supports_vision(backend)` 等辅助函数查询，新增后端只需追加配置项而不改调用分支。
- 所有可覆盖行为均通过 `GRAPHIFY_*` 环境变量暴露（`GRAPHIFY_MAX_OUTPUT_TOKENS`、`GRAPHIFY_LLM_TEMPERATURE`、`GRAPHIFY_API_TIMEOUT`、`GRAPHIFY_MAX_RETRIES`、`GRAPHIFY_DISABLE_THINKING`、`GRAPHIFY_ALLOW_LOCAL_PROVIDERS`），并提供带默认值的 `_resolve_*` 辅助函数集中解析。
- 对不可信输入采用“包装+哨兵”模式：文件内容包裹在 `<untrusted_source path=... sha256=...>` 块中，并用 `_neutralise_injection_sentinels` 将已知 chat-template 控制 token 插入零宽字符，防止提示词注入。
- Shell 钩子脚本以 Python 字符串模板拼接生成，使用 `# graphify-hook-start/end` 标记边界，安装时若已存在相同标记则跳过，卸载时用正则删除整段以保持幂等。
- 外部依赖（openai/anthropic/boto3/tiktoken）采用 `try: import ... except ImportError` 延迟导入，失败时通过 `_backend_pkg_hint` 给出 uv tool 优先的安装建议，避免在无对应后端时拖累主流程。
